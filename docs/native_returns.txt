Native return delivery
======================

A native operation runs once and reports a CettaCallOutcome. Its tag and
result_form determine the next action; the payload's spelling does not.

  VALUE / EXPRESSION          Caller interpretation may still be required.
  VALUE / COMPLETED_VALUE     One completed value, including code-shaped data.
  VALUE / COMPLETED_FRONTIER  Ordered completed occurrences, with duplicates.
  VALUE / EXPRESSION_FRONTIER Pending ordered computation, completed before use.
  FAILURE                    No further occurrence.
  RAISED                     A fault for the enclosing handler.
  INTERRUPTED                Unfinished execution, never logical exhaustion.
  SUSPENDED                  A conditional value with its delayed goals.

CettaCallReturnCursor lends these occurrences without invoking the operation,
interpreting syntax, allocating term wrappers or capturing a substitution.
Completed frontiers expand into data occurrences. An expression frontier stays
one pending computation at native delivery. A qualified choice view selects its
individual expressions for interpretation. A completed value whose payload is
itself an expression remains one value.

The caller keeps the source storage and Bindings alive. Returned occurrences
retain that environment's identity: later binding refinements are observed
through the same environment. Keeping a cursor does not acquire payload
ownership. Independent publication uses the existing owned-return image
protocol where required.

Space occurrence cursors likewise lend an optional payload with the selected
logical coordinate in one `next` transition. The payload is read from that
same physical occurrence, in either the current or detached pinned view.
Capture metadata is established after index preparation, which may contract
marked storage. Selection performs no authoritative matching, and the loan
adds no payload ownership.

CettaCallReturnCursor also implements CettaOwnedExecutionNext. Owned sequencing retains
an unaccepted return and resumes it before asking for another. A zero delivery
allowance does not pull the producer. Accepted occurrences are not replayed.
Cancellation releases the computation owner; borrowed cursor storage remains
with its caller.

A final-return certificate states that this producer has no later occurrence.
It does not solve delayed constraints, interpret returned syntax or grant
source authority. Completion is used only after the consumer accepts and any
external authority certificate is revalidated.

CettaEvalCompletion records the first incomplete cause. Later successful
returns and later faults preserve it. A malformed native frontier or payload
interrupts the evaluator with host failure; it is not an empty answer stream.

Dialect boundaries
------------------

The evaluator's sequence_native_call enters completed results directly into
their value continuation. An expression result instead resumes the caller's
saved interpretation and expected type. HE keeps its return-type judgment and
empty-frontier policy. Native expression frontiers complete into private owned
storage before the caller consumes their values; collection, raised control and
incomplete execution preserve that boundary. Authored PeTTa choice retains its
existing incremental branch policy. PeTTa's ready-call adapter keeps its Boolean spelling
and no-result policy. Foreign conditional answers retain their separate delay
service; the cursor alone does not supply a constraint solver.

Prepared intrinsic operations use their program's Boolean constructor for a
computed truth. This constructor owns its representation and lifetime. A
native Boolean leaf cannot bypass the dialect boundary merely because the
operation ran inside a compiled region.
The execution-contract presentation marks truth computations with
boolean-dispatch. A grounded data projection preserves its original carrier;
the result's Boolean shape does not grant permission to convert it.

Native argument vectors are borrowed for synchronous dispatch. Direct native
preparation keeps an unchanged source vector, allocating a replacement on the
first changed argument identity. It preserves argument order and preparation
and never writes into the source. A native operation may neither modify nor
retain the vector itself. Owning an escaping value and retaining a prepared
result view remain separate lifetime decisions.

The generated library-value-dispatch contract qualifies a legacy unlabelled
single result as completed data at either native entry. Explicit expression
frontiers retain their computation role. Payload spelling cannot change it.

Native admission and invocation
-------------------------------

The controlled closed-pure worker reports CettaCallOutcome as well. A matched
let pattern that fails is logical exhaustion, not refusal of the realization.
The caller completes that branch without reopening an answer producer or
ordinary equation entry. The same rule applies inside a prepared answer step.
Cancellation remains incomplete work. Unsupported arithmetic retains ordinary
error interpretation instead of being relabelled as exhaustion.

Compilation may remain cached after a particular input fails. This caches the
revision-pinned program, never the failed answer: the next input is evaluated
anew, and changed declarations reopen admission. Releasing execution clears
the argument loans and temporary roots on either success or failure.

Minimal collection workers return typed data or pending computation. Their
two one-step observers share the explicit instruction readback: completed
data acquires a return delimiter there, while pending source retains its
expression role. Failure emits no instruction; no Empty datum is introduced.
NativeCallReturn.MinimalObservation checks this readback against an independent
source observer. Private-name observation and native correspondence remain
separate obligations.

eval_native_application_on returns false only when the direct route declines.
An admitted call reports its actual CettaCallOutcome, including logical failure
and interruption. A missing value from a handled VALUE result is a host failure;
it cannot reopen admission and replay the operation.

EvalNativeDemand distinguishes ready arguments, immediate arguments and the
ordinary HE entry that must establish an untyped boundary. Selecting these
obligations no longer depends on whether the caller requests result metadata.
Ordinary caller attempts share one delivery implementation before trying an
applied source representation. Remaining atom-only clients use the explicit
native_outcome_expression projection after the call has been admitted.

The atom-only caller and the Prolog eval/2 callback consume the same tagged
completion service as ordinary native sequences. Completed data crosses that
boundary as data, without function/return syntax. Explicit failure contributes
no occurrence; a value named Empty remains a value. The callback's projection
removes only PeTTa's private no-result token and preserves its error boundary.

PeTTa ready calls retain conditional-answer obligations in the OutcomeSet that
the search machine installs into its delay service. Malformed obligations are
refused. Raised errors and logical failure stay control outcomes at the PeTTa
native sequence boundary, while a completed Error datum remains a value.

Streamed cardinality produces a closed integer. At native entry this immediate
literal needs no executable value delimiter. This normalization leaves code-
shaped results' completion provenance intact and does not add a source-fuel
step. Other streamed-consumer entries keep their own result metadata.

Qualification
-------------

Mettapedia.Machines.NativeCallReturn relates the array cursor to an independent
ordered list semantics. It proves exact prefixes, split resumption, final
certificates, later-context observations and a matching publication-allowance
lower bound. The bound counts delivered occurrences, not hardware work,
allocation or total evaluator cost. Pointer validity, C correspondence and
borrowed lifetimes remain native obligations.

The argument preparation laws compare copy-on-replacement with independent
eager preparation and characterize exactly when the original vector can be
borrowed. They assume immutable identities and pure preparation; they do not
license reordering evaluation or moving an effect across call admission.

The invocation model independently relates two explicit machine stages to
direct admission and invocation, and proves that entered failure cannot select
authored fallback. It also proves that erasing failure into refusal loses the
information needed to recover admission, and separates literal normalization
from the invalid normalization of code-shaped payloads.

The invocation protocol also inhabits the shared resumable MachineCore.
Split slices retain the entire frame and its debit. Resuming an entered
failure preserves the post-call world and one entry; restarting source can
repeat that effect. These counts are protocol transitions, not C activations
or another dialect's semantic fuel.

The native producer controls exercise tagged data, duplicate aliases, raised
faults, conditional answers, first-cause retention, refusal and cancellation.
The existing PeTTa specialization fixture distinguishes raw grounded Boolean
spelling from the prepared program's declared spelling. Dispatch-error controls
retain exact separate goldens for Prolog-backed and native arithmetic faults.

Shared operation interpretation
-------------------------------

The generated head/arity decoders are shared by ordinary fold admission,
Space effect analysis, register lowering and prepared compilation. They read
immutable operation descriptions; they neither prepare operands nor authorize
execution. Scope availability, source revisions, call policies and readiness
remain separate evidence. An unrestricted scope is not an existing operation.
The strict intrinsic interpretation is shared by ordinary and prepared callers.

Invocation operands
-------------------

CettaInvocation retains a BindingValue head and separate captured/supplied
argument spans. A span borrows ordinary Atom pointers or contextual
BindingValues. It owns no storage and carries no readiness, typing or source
permission. The containing frame keeps every storage and lexical owner live.

Arity admission reads only metadata. Argument lookup preserves lexical
identity and occurrence order without constructing an application. Logical
resolution reads the current Bindings at this entrance, before native work;
its result is not a certificate valid after writes, rollback or owner release.
Native consumers borrow one contiguous unqualified vector unchanged. Split
or contextual operands are reified only when the consumer needs that ABI.

The explicit syntax observer uses one expression builder and does not apply
branch substitutions or evaluate operands. Ordinary partial application and
prepared expansion share it. Publication and independent escape retain their
existing ownership services; a borrowed invocation is not a captured closure.

Source control operations
-------------------------

CettaControlOperationPlan describes an operation and its operand coordinates
in four bytes. Coordinates exclude the head. The execution-contract presentation
declares sequencing, branching, a sequence of bindings, force and return scope.
Let and chain elaborate to sequencing with different operand orders; a missing
branch is absent metadata. It is not an ordinary Empty value.

PeTTa source plans carry this description. Ordinary source execution, HE control
frames and compiled Region/OEM paths read its coordinates. Each dialect retains
its matching, demand, completion, handler and fuel policy. The description grants
no source authority, type evidence, ownership or permission to speculate.

Prepared fold instructions are an explicit restricted lowering of those plans.
A direct body entry realizes force and return scope only within that already
admitted fragment; they remain different source operations. Unsupported layouts
decline before execution. An ordinary suspension gains no Need memoization.

Mettapedia.Machines.ExecutionControl compares the indexed operand reader with
independent source-list destructuring, proves admitted coordinate bounds and
keeps force distinct from a return scope. These are source-layout laws; native
pointer conformance and whole-evaluator correspondence are separate obligations.

Boolean representation
----------------------

A prepared program's Boolean constructor supplies distinct false/true images.
Preparation refuses collapsed images and inverted canonical polarity. Plain
symbol or Bool images are program-owned; the input decoder and output constructor
use that same representation through nested operations and branches.

Boolean instructions reuse the shared scalar operation implementation without
allocating intermediate Atoms. Completed data projections preserve their carrier.
PrimitiveResultRole.BooleanCodec proves decode/encode and unary/binary truth
transport, and refusal of collapsed encodings. These laws concern the declared
Boolean domain, not arbitrary native callbacks or arbitrary data interpretations.

Compiled native invocation and residual delivery

The OEM uses the same borrowed CettaInvocation and native entry service as
ordinary calls. A generated strict, pure library description is a candidate
operation layout. The host separately checks current language/profile policy,
untyped call admission, absence of authored/translated/tabled/memoized dispatch,
closed operands and unmetered execution. HE retains its own completion adapter.

OEM_RUN_DECLINED belongs to an inline realization that leaves its caller to
select the alternate route. OEM_RUN_HOST names an actually published host
continuation. Every inline helper uses this distinction; the body runner
interprets the outcome independently of the helper's origin. An unpublished
HOST or an escaped internal decline is a provider fault.

Value-only service callbacks commit entry when they return true. A missing
result then faults in ordinary and compiled execution, without retrying the
operation. A committed space or named-state write also prevents whole-call
fallback. Interrupt and activation-budget stops retain their exact cursor,
including its committed effects, and may resume it.

Neither an executed failure nor an empty frontier permits native replay.
Single values meet the existing destination directly; raises retain their
scope. Conditional answers, interruption and completed frontiers transfer the
actual CettaCallOutcome, result role and delayed roots to a NATIVE_RETURN goal.

The return graph and delayed roots share an export session before their
producer can retire. The transport pair is metadata and is never interpreted
as source code. Ordinary ready calls and these entered returns share the same
PeTTa completion implementation and CettaCallReturnCursor. Goal operands and
the existing metadata union carry the result; a successful single-value call
needs no host goal or universal value wrapper.

The OEM cursor's next, next_above and continue interfaces carry the same
CettaCallOutcome. ANSWER transfers COMPLETED_VALUE; RAISE transfers raised
control. Host, collection, cut and stop events retain their actual cursor
state and have no return payload. The ordinary consumer validates the tag
before using the returned bindings. It never reclassifies a completed answer
through the foreign registry, even when its syntax names a callable head.
This applies equally to the first answer, a resumed alternative and a return
from an entered host continuation. Query-variable aliases and the answer
arena's lifetime are unchanged; no per-value or cursor field was added.

CettaOpenEquationStats.native_calls counts entered native calls, including
failure and interruption. A refusal does not increment it. host_goals includes
cold result transport when required, without another native invocation.
The generated open-equation-native-call runtime counter exposes these accepted
entries to evaluator controls; declaring a test function alone does not prove
that a compiled backend executed it.

PeTTa ready-value delivery preserves an ordinary symbol named Empty. Native
zero answers use FAILURE; a foreign adapter classifies zero results before
collapsing nonempty value data. The legacy private PeTTa no-result token is
projected to FAILURE at library entry. HE keeps its own Empty completion policy.

NativeCallReturn.NativeDelivery connects inline delivery and the retained
array/offset cursor to the ordered reference and the post-invocation world.
An entered empty frontier remains distinct from admission refusal. Existing
cursor split-resumption laws apply to the retained state. The models do not
claim native C correspondence or arbitrary effectful-native admission.

Ordinary invocation continuations

Activation slots, ready slots, immediate arguments, strict-ready host calls
and entered OEM returns use one search-machine delivery decision. A single
value meets its destination directly. Frontiers, conditional answers and
incomplete returns retain their tags through the shared completion service;
none is converted into a tuple and substituted for the whole result stream.
This does not add a goal transition to ordinary single-value delivery.

The canonical row-collection, batch-mutation and sequence-constructor arity
consumers read tagged native returns directly. Only the HE one-step reflective
observer still requests executable return syntax. Row decoding owns its quote
removal and evaluation demand. An entered empty collection does not decline
the operation. Arity observation remains dialect-owned: the HE preflight does
not remove PeTTa's eager argument work or its partial/over-application protocol.

ContextualCBPV gives an operational kernel for sequencing, invocation,
ordinary suspensions, ordered choice, failure, scoped handlers and native
effects. Its native entry changes the world once and installs a retained
worker. Pulling a worker can commit further effects and returns each answer's
own branch context; it does not repeat native entry. Resumption restores the
caller lexical scope while retaining the answer's logical updates.
A handler records its choice floor, so catching a raise drops
protected alternatives and preserves outer choices. Source charges are
explicit chronological occurrences, separately metered from administrative
transitions and physical slice allowance. Logical-store rollback, dialect
elaboration adequacy and native C correspondence remain separate refinement
obligations.

Scoped computation plans

Source occurrences also carry explicit return-value, construct and invoke
plans. Source roles establish interpretation authority; an operation does not
grant current callee admission, type evidence or ownership. The compiler
stores these operations without enlarging the four-byte plan. Ordinary value
and constructor consumers execute them, and OEM recognizes invocation as a
positive operation rather than the absence of a control form.

An existing adapter node with no operation can still elaborate from its own
source role. This is a migration boundary, not permission to reclassify source
from a current registry. A constructor's independently compiled children still
execute, and its head remains data after a later function registration. A
retired callable follows the dialect's existing live-dispatch protocol.
Fixed-layout control-form admission is separate from these basic operations;
receiving an explicit invocation tag does not disable a qualified lowering.

ExecutionControl.Occurrence proves source-role classification and its join to
the contextual kernel. Constructor decomposition and callee obligations are
explicit dialect services in that law; it does not claim their whole-program
adequacy or a native C refinement. Remaining argument elaboration and adapter
migration must preserve those boundaries.

The generated control vocabulary distinguishes commitment from error handling.
PeTTa's already classified cut and catch forms select these plans through its
dialect-form table. The table reads arity before operands and does not register
new globally callable heads. Both ordinary execution and OEM lower the same
commitment tag; their physical choice stacks retain their existing lifetimes.
A handler owns an error-recovery boundary, independently of the call's cut
delimiter. Returning from an inner call restores the caller's cut delimiter.

ContextualCBPV represents scope entry and commitment explicitly. A delimiter
records the current outside continuation; commitment retains that exact suffix
and the current logical branch and effect world. Later choices remain live.
ExecutionControl lowers the admitted source layouts into these computations;
the commitment transition also refines the independent ScopedCommit CPS law.
Source charges remain explicit, so insufficient semantic fuel retains pending
commitment rather than converting suspension into logical failure. Complete
dialect elaboration and native C correspondence remain separate obligations.

A pending check remains part of a conditional return even when a caller asks
to project away substitutions. Projection materializes both the value and
check under the merged context, then retains their reachable bindings and
branch state. A preserved-environment return also transports its delayed root.
The existing whole-outcome relocation owns both roots after the source retires.
Transport does not interpret a client's check protocol. Registration and
discharge belong to the consuming relational/constraint machine.
Row collection applies the same quote/collection observation to ordinary and
conditional values. Each resulting occurrence carries the pending check;
an empty collection produces no row and never reenters the native provider.

ConditionalContextProjection reuses the finite Horn worklist to compute the
least support closed under store reads. It proves both directions of finite
substitution preservation for the value and check, including transitive reads
and unreachable cycles. Native graph relocation and attributed-variable
correspondence are separate obligations tested at the runtime boundary.

Owned sequencing

CettaOwnedBind sequences a producer and its admitted child computations.
The producer's packet stays pending while a child reads its value, provenance,
checks and environment. Child retirement precedes producer acceptance. A
consumer refusal keeps the same child return pending, without entering the
child or pulling the producer again. Cancellation releases the child first.

Declined child admission retains the actual packet for another worker;
cetta_owned_bind_resume installs that worker without repeating the producer
or admission callback. A handoff inside an entered child retains that child's
own residual. It does not permit restarting its admission. Logical zero skips
publication, raised control bypasses the child factory, and incomplete causes
remain separate from exhaustion. Final certificates are checked after child
execution and actual consumption, so an invalidating effect cannot close the
producer early.

One next operation pulls at most one producer occurrence. An admitted empty
child can pause without publication. The output allowance still counts
accepted returns; these administrative pauses do not define source fuel.
Compiled-to-ordinary residual execution uses this sequence for its decoded
caller continuation. The source image and selected binding context outlive
the child; publication refusal stops the retained computation. A whole-call
collector over already-ready values remains a native leaf. Applying the
generic per-element protocol there failed its size-series cost checks.
Compiled-cursor controls also compose their existing owned execution adapter
with the sequence. Prepared-native lowering uses the retained boundary below.

Source readback exports a closure: decoded syntax plus captured bindings.
Installed slots and literal values become fresh ports; static constructor
heads retain their operation identity. A delivered slot keeps
the pending computation, including inner callers, so closure conversion neither
interprets ready code-shaped data nor freezes a computation into data. Export
stages the complete binding image before replacing its initialized output;
refusal leaves that image unchanged. Decoded syntax retains the program's source
dialect and its adapter's demand, handler and completion obligations.

The ordinary owned consumer uses the existing contextual call spine, keeping
the world live during execution. The search-machine consumer lowers capture
installation to ordinary unification goals under each branch's own checkpoint.
Those goals' operands are allocated before the retained heap mark, so rollback
does not invalidate later alternatives. Each branch still has one authoritative
binding state; the capture image is temporary immutable handoff metadata.

COMPLETE with a LIMIT handoff is a physical pause. An entered native worker
keeps its actual cursor, packet and continuation. The parent schedules a prepared
resume goal, admits that transition through its controller, and only then grants
one more child transition. Cancellation can refuse the same pending goal without
refilling or advancing the child. Finite-purse parent hosts retain canonical
selection before prepared entry. Qualified pure source frontiers can still
transfer to actual remaining equation choices after every caller is decoded.
Allocation failure and invalidation keep their incomplete causes and cannot
reopen the entrance call. Reading a native frame exports its actual continuation
without consuming its packet or delayed roots. A native tail's residual is its
delivered hole; completion still needs the dialect worker.

ResumptionClosure proves closure conversion against independent source and
target interpreters, preserving values and committed effect traces through
nested callers and failure. Its finite context model separates ready values
from the pending hole. Native graph transport, private-ID allocation, source
fuel, constraint registration and dialect correspondence remain separate duties.

OwnedBind lowers finite contextual component traces to OwnedPullDriver's
explicit child frames, with an independent recursive trace specification.
The checked laws cover ordering, duplicates, admission versus zero, scoped
packet retention, replacement workers and split effects/history. General live
worker refinement, native pointer ownership and source-fuel joins remain open.

Prepared native continuations

The source-view native_call callback returns CettaCallOutcome. False declines
before entry; true retains the operation's result tag and interpretation stage.
The scalar executor does not invoke library natives. Native-required programs
use the retained step program, whose ready operand slots and continuation locals
are separate from source syntax. Equation-only consumers decline those programs
before entry until they own the same completion protocol.

A completed ground value continues directly. A frontier becomes an owned
producer below its child continuations, retaining duplicate occurrences and
borrows until each child retires. Logical zero leaves no child. Raised control
bypasses the value continuation. Interrupted and malformed results keep their
own incomplete causes. A private Empty or Error spelling does not choose any
of these machine states.

The search-machine entry lends immutable argument graphs until its parent
heap is reclaimed. A synchronous completed native call keeps that loan. The
existing external-owner guard protects the synchronous pull from caller
relocation during reentrant completion and ends before the consumer resumes.
A native residual owns the frontier, actual tagged packet and live locals
before suspension. Register readback and step execution use this same retain
boundary. A completed register region copies its answer out of reusable
program storage only when collection created survivor storage.

Cursor.NativeBorrowedReturn checks graph transport, ordered control traces,
duplicate occurrences, finite event prefixes and release safety against an
eager-transfer model. Its graph observer forgets storage homes; payload
contents, C root enumeration, copy-session sharing and authored source fuel
remain separate obligations. Native controls cover borrowed identity and
aliased residuals after source reclamation.

native_boundary lends either an unentered ready invocation or its actual
pending packet. resume_native takes a replacement producer through the existing
owned-bind service and resumes the saved step and locals, without rebuilding
or calling the source native. Ordinary completion interprets only an expression
the producer left executable. Completed code-shaped data remains data.
Conditional or foreign-resource packets keep their loan when this closed
worker lacks the constraint or ownership authority to complete them.

The ordinary closed-answer collector uses owned sequencing. Once a native
worker has entered, a resource or publication failure cannot retry the original
call. Committed effects and accepted prefix images remain recorded. The same
source, library, declaration and foreign-capability authority protocol guards
ordinary residual owners and these saved native continuations. Completion
workers are checked before their retained caller runs. Explicit and inherited
source-fuel purses retain ordinary execution until their lowering is qualified.

Where equation matching is unique, register execution lowers this same step
program. The first registers keep the step slots' coordinates. A cold PC map
names each instruction's source step; matching permission remains separate
from the native producer's answer multiplicity. Ordinary completed values stay
in registers. Other native outcomes save only initialized live logical slots,
the actual returned packet, and every waiting caller. One copy session rehomes
their shared reachable graph before reusable program storage can be entered
again. The resulting owned frontier resumes the same step program.

A physical transition allowance may be extended only at an intact call
frontier. Register execution reconstructs that frontier before exhausting its
allowance. It shares exhausted-caller retirement with CPS entry; a native
producer retains its own pending loan. This neither replenishes a semantic fuel purse nor retries a native
operation. Source invalidation refuses the extension; scratch exhaustion inside
an operation does not license it.

Callee refusal and physical-budget exit share ready-call handoff to the CPS
matcher. A callee miss retains the dialect's logical failure or unreduced value;
it does not turn into host failure after native entry. User calls in these
programs remain explicit invocation steps even when their bodies are otherwise
deterministic. Dynamic heads and unsupported arities decline before native
arguments run. HE native branches retain ordinary held-operand/type completion
until its source-error observation and continuation adapter are joined.

NativeReader in OwnedBind joins indexed NativeCallReturn delivery to the
explicit child-frame driver and its independent list specification. It proves
ordered events, retained cursor handoff, distinct terminal reasons and split
history. Pointer ownership, the C step compiler and dialect source-fuel
correspondence remain separate obligations.

Typed prepared-callee consumers

The OEM keeps immutable source eligibility for recursive prepared entry.
Stable compilation refusal belongs to the callee's revisioned program cache,
consulted by head before argument resolution. An open input, observer refusal
or input-dependent execution refusal affects this call alone. It cannot
disable later inputs, another cursor or a different caller. The callee's
closed-call boundary still revalidates the actual program before execution.

CalleeRefusalScope joins exact revisioned negative facts to the independent
admission route and proves that transient refusal leaves later calls eligible.
The native controls exercise open and closed refusals, changing owner evidence
and a real OEM caller entering the prepared executor after an open call.

Controlled open-entry scalar execution transfers CettaCallOutcome, including
completed values, logical failure and interruption. The lexical adapter and
collection consumers read those tags before using a payload. Lexical completion
does not veto a completed value by its Error or Empty shape. Compilation,
argument demand and escaping-resource admission remain separate checks.

Named and lexical OEM prepared calls share one terminal-result decoder.
Completed values meet the existing destination, failure ends the branch,
interruption stops the cursor, and raised control uses its publication path.
The named scalar worker still requires terminal completion. Lexical workers
may additionally admit a native tail after pure operands, bindings and branch
conditions. Native operands, binding producers and conditions cannot themselves
enter a native; compiled named callees retain their scalar contract. Metered
source execution and bounded OEM searches retain ordinary execution. A raw
Atom-only caller cannot enter the native tail.

Controlled tail entry transfers the provider's complete packet, including a
malformed packet: once entered, the operation cannot select fallback. Native
operations and lexical native tails use one OEM completion boundary. Completed
closed data meets the destination directly; unfinished expressions, frontiers,
open values and conditional answers transfer to the existing host return frame
together with the actual caller continuation. Term and delayed roots share one
transport session. Malformed packets fault, and entered failure never replays.

NativeTailReturn relates independent source evaluation to terminal lowering,
proves at most one native entry per admitted body, and preserves the exact
packet. It includes local binding and pure branching. Source fuel, named callee
admission, allocation and native pointer correspondence remain separate
obligations. NativeCallReturn and contextual return refinements provide the
subsequent return-selection and continuation laws.

Executable body metadata is shared by invocation roots and equation bodies.
Matching patterns and Space occurrences stay in equation metadata. Direct
parameterized entry binds distinct parameter identities to positional ready
values, clears fresh local slots and runs the same continuation steps and
register lowering. It creates no Space equation. The root has no equation
frontier, and scalar entry refuses it; its owner uses the body cursor.
OEM lexical invocation selects these bodies after scalar/tail admission, over
closed ready inputs and the existing relational result destination. An ordinary choice frame
owns the callee cursor and the existing caller continuation. Each answer
restores the caller's binding snapshot; committed effects are not rolled back.
The first pull borrows operands and uses the caller arena synchronously, so a
final value needs no second materialization. An unfinished callee may continue
borrowing that arena while its caller frame pins the callee's storage position.
Binding, trail and store snapshots still restore independently at each answer.
Before parent collection or arena export, the callee copies its exact live
frontier, including saved locals and shared continuation tails, into private
storage. Native suspension seals its retained roots at the same ownership
boundary. Failed transfer after entry stops execution; it cannot reopen source
and replay committed effects. The same relocation worker compacts owned cursors.
Cuts, cancellation and frame retirement release
that owner. Each compiled body may keep one empty worker of at most 4 KiB of
metadata; it retains no arguments, caller arena, authority callback or execution
allowance. Concurrent and escaped workers remain independent.

Initial, resumed and unmatched completed values use the same OEM destination
matcher. Rejected partial matches restore the caller snapshot before the next
callee answer. Immutable constructor-output shapes can reject a fixed mismatch
before building an answer; unknown operands remain variables in those shapes.
This selector applies only to final callee returns, never intermediate values
consumed by a retained continuation. Nonlinear bindings and uncertain shapes
still use exact matching. Per-body register admission also retains CPS entry
when a callee has multiple matching alternatives, avoiding setup for a worker
that would immediately hand off to the same continuation machine.

A native that invalidates source authority still retains its actual packet
and caller continuation. Native-boundary inspection copies the borrowed return
descriptor without executing its producer. Stale authority permits that read
and refuses completion or ownership transfer into a replacement computation.
The pending packet cannot be erased into pre-entry refusal.

ParameterizedBodyEntry relates independent named parameter binding to slot
initialization and transports that environment through every contextual CBPV

remain separate obligations.

Callable elaboration preserves enclosing-form captures. Read-only captured
cells may remain in the scalar worker's authoritative OEM store. A scalar

those captures, so it retains ordinary execution. Continuation-bearing body

unsealed variables inside a lambda are not silently made fresh at each call.
Completed values containing this cursor's cells meet its destination directly;
foreign variables retain the host binding-import boundary.

against saved-binding source sequencing, retaining world effects, duplicates,

The search machine selects this worker for a closed eligible callee even

Prime argument roles
--------------------
Atom domains hold syntax. Proc domains denote shared computations; an unused
argument remains unforced, and demanding it repeatedly shares its evaluation.
Specific domains such as Number request a computed value of that type. Result
types classify what the body computes; an Atom result does not hold the body.

An explicitly computational source argument records
PRIME_NEED_SOURCE_COMPUTATION in its existing Need cell. Open logic variables
in that source cannot turn the demand into a syntax template. Forwarding an
inferred pending reference into a computational domain creates a value view
that shares the original demand. Cache updates, imports and independent frame
transport preserve this role. It grants no force or inspection authority.
Undeclared parameters keep the existing inferred template behavior.

Native services must inspect ordinary atom values rather than treating private
held carriers as guest syntax.
Explicit interpreters open code at their own boundary. A space also stores
ordinary atoms: the existing graph projection removes private held carriers
before publication, preserving shared subterms. The read boundary supplies the
data role again. Registry values keep their separate value-role protocol.

Selecting an if branch demands that branch's computation; it does not activate
a held value forwarded by the caller. Explicit eval still activates that value.
Reading a held True or False inspects the Boolean without evaluating arbitrary
held syntax in the condition position. The same distinction applies to native
typing: the checker inspects the underlying syntax, including its variable
sharing, rather than treating a private data carrier as an unknown constructor.

A matching wrapper declares its pattern as Atom and its executable template
as Proc. The template runs after matching, once per answer occurrence, and is
not demanded when there are no answers. Values bound from stored atoms remain
data when forwarded through that template. Streaming string helpers likewise
use Proc for a computed state or segment argument, allowing a state constructor
to run before its result is inspected.

Patterns that inspect held quotations use the same binder-aware code view as
ordinary quotations. A bound name cannot become a free name merely because
the quoted value crossed a data boundary; extracted contextual code retains
the binders needed for an explicit opening.

Native typing verdicts use the existing completed-value return form. Returning
proof evidence does not invoke an equation that happens to share its head.
A KEEP demand or a completed Prime value returns before executable-call
admission; retaining such data grants no permission to execute its payload.

A computed space selector that produces a context-role name uses the same
role policy and read observation as that literal name. Ordinary registry-name
fallback retains its existing behavior.

A native service reached through borrowed synchronous interpretation uses an
ordinary owned child receiver while the borrowing caller stays live. Retained
or controlled ancestors keep their existing admission and lifetime boundary.
