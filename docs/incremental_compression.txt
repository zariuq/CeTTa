Checked incremental compression
===============================

The implementation is an authored PeTTa library. It requires no Python or Prolog
runtime and adds no learner-specific C primitive. Python is used by the separate
correspondence gates as an independent reference.

For a small runnable IC + ILP example, see docs/ic_ilp_demo.txt. The
demo-ic-ilp target learns a helper from current library source, verifies the
complete archive and reconstruction, and uses the helper in typed composition
with positive and negative examples.

The structural-cost PLN experiment is described in docs/ic_pln_poc.txt. It
retains an explicit failing gate when two real-source improvements are not
found; its controlled rule-head tests are separate evidence.

Theory, inspirations and provenance
----------------------------------
The feature/descriptive-map framework, incremental compression theory and ALICE
originate in Arthur Franz, Oleksandr Antonenko and Roman Soletskyi, "A theory of
incremental compression", Information Sciences 547 (2021), 28-48:

  https://doi.org/10.1016/j.ins.2020.08.035
  https://arxiv.org/abs/1908.03781

WILLIAM, by Arthur Franz, Michael Löffler and contributors, is an implementation
inspiration and a capability/reference-workload source for this learner:

  https://gitlab.com/occam_ua/william

Its operator/inverse learning approach and sequence, regression and clustering
families inform the programme. CeTTa's learner is an independent implementation;
it does not require WILLIAM at runtime. Intellectual credit is distinct from
whether implementation source is copied. No claim of full WILLIAM coverage or
superior search quality follows from the controls reported here.

The Mettapedia formalization was also informed by and compared with the separate
ic-theory developments in the dmacd and af271 lineage:

  https://github.com/dmacd/ic-theory
  https://github.com/af271/ic-theory

Results are developed over Mettapedia's shared computability and conditional
plain/prefix foundations, with explicit machine and quantifier assumptions.
Compilation of an external formalization does not by itself discharge those
correspondence obligations.

The CeTTa/Mettapedia work contributes its particular typed/scoped representations,
complete archive codecs, checked reconstruction, resumable execution machinery
and implementation-correspondence controls. Algorithmic Lean laws and finite
runtime checks are separate evidence; neither practical cost descent nor a
bounded search proves the paper's ideal shortest-feature hypotheses.

Layers
------
lib/petta/lib_incremental_compression.metta owns acceptance, first-accepted
selection, bounded iteration, reconstruction and cost accumulation.
lib/petta/lib_ic_repeated_block.metta supplies a closed bit-sequence family.
lib/petta/lib_ic_syntax.metta supplies exact ordered-syntax factoring with fresh
representation references. These references are not host-language variables.

Import the desired family, for example:

  !(import! &self "lib/petta/lib_ic_syntax.metta")

Counts and search budgets use IC:Z / (IC:S predecessor). This explicit boundary
does not silently treat fractional numbers as natural budgets or reference IDs.
Syntax values are (IC:Leaf symbol), (IC:Ref natural), or (IC:Pair left right).
Leaves must be symbols, not numbers whose matching could promote 1 to 1.0.

  (ic:compress kernel proposals fuel source)
  (ic:compress-generated kernel fuel source)
  (ic:restore kernel features residual)
  (ic:plan-cost kernel features residual)

Compression returns (IC:Plan features residual stop). IC:BudgetExhausted records
the search bound; IC:NoCandidateAccepted refers only to the supplied finite
proposal family. Neither result asserts global incompressibility. Reconstruction
returns (IC:Some source) or a refusal/unavailable result.

Kernel operations are extract, expand, feature-cost, data-cost and, optionally,
propose. They have a deterministic pure contract with natural costs and the
IC:Some/IC:None boundary. The current qualified instances satisfy that contract;
this interface does not prove arbitrary user-defined callbacks pure, total or
single-valued. Multivalued inverses must expose branch choices as distinct
proposals rather than hide a first-answer selection inside extraction.

Costs
-----
The two initial instances use explicit constructor-size models, including feature
and residual costs. They do not claim prefix-code bit optimality. A future binary
codec must charge its framing, alphabet/library and reference costs explicitly.
Source labels and reference IDs remain part of the representation observation.

The binary library now provides the reusable record framing for that codec:

  !(import! &self (library binary))
  !(import! &self (library tensor))
  !(let* (($name (binary:utf8 "example"))
          ($payload (tensor:from-values u8 (3) (0 1 255))))
      (binary:pack-fields ($name $payload)))

Fields and results are immutable, fully supported rank-one U8 tensors. The wire
contains E2(binaryBits(fieldCount)), then E2(fieldBits) for every field; bits are
most significant first. Zero padding completes the final byte. Thus dictionaries,
definitions and residuals can use nested records without hidden field boundaries.
binary:packed-length returns the exact encoded byte count without packing data.
Its (Binary:FieldLengths (length ...)) input measures the same record from exact
nonnegative integer byte lengths, without allocating those payloads. Invalid
lengths and encoded-size overflow remain explicit faults.
binary:unpack-fields returns (Binary:Fields fields), or a completed Binary:Fault
for malformed framing, noncanonical lengths, unaligned fields or trailing data.
Unsupported non-tensor inputs remain available to authored extensions.

binary:utf8 and binary:from-utf8 convert explicitly between text and byte vectors,
validate UTF-8 and retain embedded NUL. Packed binary fields themselves may contain
arbitrary bytes. Views preserve their logical byte order; missing sparse entries
are never filled implicitly. The library has no compression-specific evaluator
case and is activated through the ordinary library registry.

binary:unsigned encodes a nonnegative machine integer as minimal big-endian bytes
(zero has an empty payload); binary:from-unsigned reads that representation.
Redundant leading zero bytes, negative inputs and values above the machine-integer
range are refused. Floating-point inputs are not silently treated as integer IDs.

binary:unsigned? inspects the actual nonnegative integer representation directly.
The schema and template validators use it without constructing temporary byte
vectors for every operator or hole ID.

binary:symbol-utf8 and binary:from-symbol-utf8 convert literal symbol names through
the native symbol interface. They do not use the source reader. Symbol names
exclude NUL, while String and opaque byte payloads can retain it.

The initial reference compressors retain their constructor costs. The IC1 archive
path below supplies complete byte accounting for admitted first-order templates.

Immutable compact forests
--------------------------
The ordinary dag library stores Binary:Leaf and Binary:Node forests through a
private instance of the runtime's existing collision-checked structural store.
Only packed byte payloads and child coordinates are retained. It does not keep
an unfolded Atom tree alongside the compact records.
Tree import memoizes source identity for the duration of its private build,
reusing the existing u32 indexes as an exact two-level u64 index. Active source
entries detect cycles; completed entries avoid revisiting shared children. No
source pointer or mutable import memo survives publication.

  !(import! &self (library dag))
  (dag:from-forest trees)
  (dag:from-records (Dag:Forest roots records))
  (dag:export handle)
  (dag:roots handle)
  (dag:node handle index)
  (dag:unfold handle index)
  (dag:fold-unique handle leaf-algebra node-algebra)
  (dag:stats handle)
  (dag:close handle)

An exported record is (Binary:Leaf bytes) or (Binary:Node tag child-indices).
Every child index must point strictly backward. Root order, duplicate roots
and duplicate child edges survive. Import validates the whole record table
before publication and canonicalizes exact duplicate records. A leaf and an
empty node remain different even when their payloads agree. Opaque bytes do
not acquire numeric promotion, text parsing or approximate equality.

Public indices are dense coordinates within one forest. They are not stable
cross-forest identities or owning references. Copies of a live handle retain
the immutable store; explicit close invalidates aliases. Printing and reparsing
or arithmetically reconstructing its visible ID cannot recover ownership.
Dag:Stats reports node count, edge count and conservative retained-resource
accounting, not total process RSS.

fold-unique visits each stored node once, in chronological order, then projects
the ordered roots. For a pure deterministic algebra it agrees with folding the
unfolded trees. With effects or choice it explicitly observes that unique-node
schedule; it must not silently replace a tree fold under those observations.

lib/petta/lib_dag_codec.metta supplies dag:pack and dag:unpack through the same
framing and schema machinery as IC1. The DAG1 envelope contains its version,
root vector, payloads and all references. Decoding creates a new owned forest,
not authority for a previous handle. IC1's logical source codec and default
acceptance cost remain unchanged.

dag:encoded-lengths calculates each root's exact unfolded-tree encoding length
through a memoized length algebra. It does not allocate the expanded encoding.
The 21-record focused control represents 1,048,576 leaf occurrences per root;
each unfolded encoding is 51,310,291 bytes, while the DAG resource accounting
is about 20 KB. This is a representation control, not an application speedup or
total-process memory comparison.

The ordinary recursive binary-tree:byte-length is also available as a reference
length evaluator. Replacing archive acceptance's encoder with this evaluator
was slower in a paired local experiment and was not retained. The explicit
bench_ic_archive_cost.py command preserves both implementations as controls;
it is not part of the ordinary correctness suite.

Parameterized templates
-----------------------
lib/petta/lib_ic_templates.metta provides ranked first-order matching and pairwise
generalization in ordinary MeTTa, using the canonical role/index schema from the
Gauthier theory. A source node is (IC:Node operator-index children). A pattern may
also contain (IC:Hole role index), where role is Root, Code or Value. IDs are exact
nonnegative machine integers; source variable syntax is not an implicit hole.

The ordered signature contains (IC:Operator result-sort slots) rows; each slot is
(IC:Slot role sort), with symbol sort labels. A row's position is its operator ID.
Admission checks result sorts, child counts, hole roles and consistent hole sorts.
No source operator is executed by matching or expansion.

  (ic-template:match signature root-slots patterns sources)
  (ic-template:generalize signature root-slots left-sources right-sources)

match returns IC:None for a disagreement, (IC:Some environment) on success, or an
IC:Invalid result for malformed admitted inputs. A forest shares one environment:
matching a rewrite's left and right sides separately would lose their constraints.
Distinct corpus occurrences use separate environments. expand-list reconstructs
an admitted pattern forest from its returned environment.

generalize returns (IC:Generalized patterns left-environment right-environment).
Repeated disagreement pairs share a hole. IDs are first-occurrence positions in
the complete hole stream, including repetitions; swapping the input pair keeps
the schema but swaps its residual arguments. This supplies pairwise search seeds,
not a complete template grammar search. It does not itself accept compression or
claim that introducing a helper is profitable. Binder templates require the
existing scoped matcher and a source adapter; they are not erased into this
first-order representation. Lossless source capture and source-template archive
reuse are described below. Scoped helper transformations, corpus-guided
refinement and the full learner remain subsequent work.

Source observations and source-level acceptance
-----------------------------------------------
The ordinary syntax library reads source through the active document reader,
without evaluating it. PeTTa imports it with (library syntax); Prime imports
syntax. The syntax reader, not a separate compression tokenizer, owns dialect
normalization and the set of admitted source forms.

  (syntax:read text)
  (syntax:restore document)
  (syntax:freeze source)
  (syntax:write document)

An ST1 document records its reader language, resolved version, profile and ordered
source forms. Each form includes a first-occurrence variable inventory. Repeated
references retain identity; anonymous variables are distinct occurrences. Names
are presentation data, not identity keys. Quote syntax, duplicate declarations,
all expression children and literal payloads survive. Comments and whitespace are
not part of this syntax observation. Capturing syntax establishes no binding,
purity or execution permission.

restore reconstructs a private owned SourceSyntax value with fresh internal
variable identities. These variables belong to the quoted source, not to the
enclosing program's logical environment. The value owns actual restored syntax,
not a copy of the input document. freeze observes that reconstructed syntax.
Separate restores have separate identity; compare their frozen documents for
portable syntax equality. Runtime handles are not source literals.

write preserves source names and dialect string rules, then checks that the
active reader returns the same complete document. A changed reader is refused.
A document may be transportable without being printable by that reader: two
distinct identities with the same display name, for example, must not silently
collapse during emission. Unsupported emission returns Syntax:Fault.

lib/petta/lib_source_codec.metta supplies syntax:pack and syntax:unpack through
the common schema/framing machinery. ST1 charges reader metadata, name inventories,
literal kinds and packed payloads, ordinals and every expression boundary. Fixed
I64/F64 payloads retain their type and bits; payloads are never approximate keys.

lib/petta/lib_ic_tree_archive.metta maps ordered byte trees into IC1 using the
existing immutable DAG and stable key factorization. Payloads are nullary typed
operators; a node-arity operator receives a packed tag and its ordered children.
Repeated edges and roots remain separate observations. The dictionary, operator
arities, literals, definitions and substitutions are charged archive data.

lib/petta/lib_ic_source_archive.metta maps a captured source into a header plus
ordered form roots. A whole rule retains one shared variable inventory across
its left and right sides. The first-order learner can factor those inert source
records; it does not perform a capture-sensitive rewrite inside the source or
install a learned rule into a running space.

  (ic:prepare-trees forest)       -> (IC:TreeArchive archive), or refusal
  (ic:restore-trees archive)      -> (IC:Some forest), or IC:None
  (ic:prepare-source document)    -> (IC:TreeArchive archive), or refusal
  (ic:restore-source archive)     -> (IC:Some document), or IC:None

The ranked-tree intermediate must not inflate the baseline used to accept
compression. Source-level artifacts therefore use a SIC1 envelope: the common
three-field framing of UTF-8 "SIC1", UTF-8 codec name, and complete packed payload.
ST1 and IC1 are explicit alternatives. The envelope and all payload bytes count.

  (ic:source-pack document)        -> plain ST1 source artifact bytes
  (ic:source-from-archive archive)  -> learned IC1 source artifact bytes
  (ic:source-unpack bytes)         -> (IC:Some document), or IC:None
  (ic:source-check original current candidate)

source-check independently reconstructs all three complete documents, checks
them against the original observation and accepts only a strict reduction in
complete artifact byte length. The ordinary resumable search uses this contract
under IC:SourceArchive; IC:ProgramArchive remains the intermediate archive model.
An IC:SourceTemplate proposal contains archive, name, slots and patterns. Proposal
construction cannot bypass source reconstruction or complete-cost acceptance.

The focused real-wrapper control factors four authored list helpers from 12,517
to 8,675 IC1 bytes. Plain ST1 is only 2,307 bytes, so source-level acceptance
correctly refuses that candidate. A separate repeated-rule control preserves
all twelve declarations and reduces the complete SIC1 artifact from 7,418 to
5,623 bytes. These are representation controls, not held-out learning results,
execution speedups or comparisons against a general-purpose text compressor.

SourceFrame.lean proves fresh variable reconstruction and occurrence/alias
preservation. TreeArchive.lean connects complete dictionaries and indexed
byte-tree encoding to actual template matching and reconstruction. These are
algorithm laws, not universal verification of the native implementation or
permission to erase scope information.

  make test-source-codec

This focused gate checks independent ST1/IC1/SIC1 bytes, source preservation,
current-reader emission, actual loading/execution, codec choices and source-level
search. It is not added to the ordinary test dependencies.

Scoped parameterized templates
------------------------------
lib/petta/lib_scoped_templates.metta supplies an ordinary MeTTa instance of the
shared sorted binding-term matcher and partial reconstructor. It does not add
another binding calculus or an evaluator dispatch case.

  (Scoped:Family sorts operators parameters)
  (Scoped:Operator name result-sort ((Scoped:Slot binder-sorts child-sort) ...))
  (Scoped:Parameter name role dependency-sorts result-sort)

Names are text metadata. Sort labels are explicit symbols or UTF-8 strings;
they are compared without conversion between those kinds. Parameters retain
Root/Code/Value roles. Operator and parameter positions are exact nonnegative
integer coordinates within the declared family, not hashes or host variables.

The wire carrier is the existing Binding.WireCodec.Data: Wire:Atom holds a
natural, Wire:Pair holds two data cells. Terms and argument vectors follow the
original Binding.Term/Args codec. Source operators use a table ordinal; schema
operators use the tagged base/parameter sum. These helpers construct that wire:

  (scoped:variable index)
  (scoped:base operator-index children)
  (scoped:rigid operator-index patterns)
  (scoped:meta parameter-index arguments)

  (scoped:match family ordinary-context result-sort pattern source)
  (scoped:expand family ordinary-context result-sort captures pattern)
  (scoped:match-many family ordinary-context root-sorts patterns sources)
  (scoped:expand-many family ordinary-context root-sorts captures patterns)

Matching returns IC:None for an unsupported/disagreeing match, IC:Invalid for
malformed input, or (IC:Some (Scoped:Captures variables parameters)). Expansion
independently reads those captures; it never returns a cached source term.
Unused parameters may stay absent. A used but missing capture is refused, not
replaced by an invented value or an unexpanded hole.

Every binder field uses its declared sort prefix. Contextual arguments must be
distinct bound variables at the declared sorts, in the supplied order. Subsets
and permutations are supported. Recovery rejects references to unselected
ambient binders, while keeping binders introduced inside a captured body local.
Repeated parameters compare the recovered bodies, including at different depths.
Ordinary rule variables have closed images and cannot capture object binders.
Repeated or nonvariable argument spines can be declined even when a more general
higher-order solution exists. This is not general higher-order unification.

match-many shares one accumulator across rule components. It must not be replaced
by independent matches of each side. Raw wire admission checks constructor
markers and list terminators as well as indices: numeric matching does not make
0.0 an acceptable encoding of the natural marker 0.

lib/petta/lib_scoped_module.metta projects finite AST operator families from the
existing LanguageDef carrier produced by the module reader:

  (scoped:family-from-language language parameter-declarations)

The result is the same Scoped:Family used by ordinary registration. Simple
base-sort parameters and supported single-binding parameters are derived from
their authored type fields. Unsupported carriers/parameter forms return a
Scoped:Refused value; they are not silently given a nonbinding interpretation.
This is a signature projection, not permission to execute a module's equations,
rewrites, premises or notation. Plain MeTTa source needs no module conversion.

The focused gate reads and assembles the existing BindingValues.module, derives
its Name/Expr binder fields, matches a contextual template, reconstructs an outer
reference, and checks the corresponding term through native LanguageDef
admission. An ordinary registered family gives the same observations. Changing
the binder declaration changes admission. Constructor names are never invoked.

ScopedTemplates.lean proves direct reconstruction from the actual scoped
matcher's partial captures, without requiring a total completion.
ScopedTemplateWire.lean supplies the finite operator-table codec instance for
arbitrary decidable sort labels, using the shared term/argument codecs.
The controls include an unused sort with no closed inhabitant: no total ordinary
or metavariable assignment exists, yet the used template still reconstructs.
These laws and executable conformance controls are not a universal proof of the
MeTTa evaluator, nor automatic higher-order template discovery.

  make test-scoped-templates
  make test-incremental-compression

The second command explicitly joins the implemented IC component gates.
Neither command expands ordinary make test. Numerical learning, automatic scoped
proposal generation, library export and held-out execution-cost qualification
require their own adapters and evidence; the later sections describe the
implemented interfaces and their remaining limits.

Closed protocol values and scoped archives
-----------------------------------------
lib/petta/lib_binary_value.metta transports closed protocol values as BV1.
Its scalar profile distinguishes flat symbols, UTF-8 text, exact nonnegative
machine integers and fully supported packed U8 vectors. Ordered expressions
retain every child, including duplicates. Text permits embedded NUL. Live
variables, runtime handles, internal carriers and structured symbol names are
not serialized by this profile. Other numerical literals belong in explicitly
typed packed payloads, not silently rounded or reclassified protocol scalars.

The schema uses tags 1 Symbol, 2 Text, 3 Natural, 4 Bytes, 5 Expression and
6 Archive. Scalar forms have one payload leaf; Expression has one zero-tagged
vector of recursively encoded forms. Archive has the text version BV1 and one
value form. All records use the existing recursive E2 framing. Independently
implemented fixtures check the complete bytes, not only a label-table checksum.

binary:value-kind classifies the physical portable representation; it is not
a purity, ownership or execution certificate. In particular, PeTTa may report
a builtin symbol's semantic metatype as Grounded. That does not change its
physical symbol bytes. Schema symbol fields use the physical guard without
changing PeTTa reflection. Decoding constructs expressions with cons-atom and
does not invoke a decoded head, even when it spells quote or println!.

lib/petta/lib_ic_scoped_archive.metta combines the same scoped matcher,
protocol codec and ordinary resumable controller:

  (Scoped:Archive "SC1" sorts operators definitions items)
  (Scoped:Definition name ordinary-context parameters root-sorts pattern-forest)
  (Scoped:Raw origin root-sorts source-forest)
  (Scoped:Call origin definition-index (Scoped:Captures variables parameters))

The original archive carries only its base signature and raw sources. An unused
proposal grammar is not charged to the original in order to make a later result
look smaller. Each installed definition carries its full parameter declarations,
context, root sorts and pattern forest. Calls carry the actual partial captures.
Origins, component order, duplicate occurrences and every unmatched source
remain part of the reconstructed observation and the encoded cost.

  (ic:prepare-scoped family source-packets)
  (ic:scoped-factor archive name ordinary-context parameters root-sorts patterns)
  (ic:scoped-pack archive)
  (ic:scoped-unpack bytes)
  (ic:scoped-check original-bytes current-bytes candidate-bytes)
  (ic:learn-scoped original-bytes (IC:Candidates proposals) quantum)

A source packet is (Scoped:Packet origin root-sorts source-forest). Preparation
returns (IC:ScopedTask bytes). A proposal is (Scoped:Factor base-archive name
ordinary-context parameters root-sorts patterns). The explicit base permits a
proposal to refer to an earlier checked snapshot. The final checker still
compares with the original task. Existing definitions use base syntax; this
profile does not implement recursive or arbitrary inter-definition references.

Factoring selects disjoint whole-packet sites and shares one capture environment
across the forest. Expansion independently validates and reconstructs each call.
The search adapter requires at least two matching occurrences, accepts only a
smaller complete artifact, records the current equation space as a dependency,
and returns the ordinary IC:PreparedSearch for ic:resume, ic:cancel and
ic:release. These entry points search supplied proposals; automatic scoped
grammar/corpus proposal discovery is not established by this adapter.

lib/petta/lib_ic_packed.metta owns the common packed-artifact check, used by the
source and scoped adapters. A domain supplies an observation decoder and an
acceptance criterion against the original observation. Both the current and
proposed artifacts must meet that fixed criterion. It need not be transitive:
the control with successive observations 0, 1, 2 accepts 1 within a tolerance of
1 but refuses 2 against the original 0, even though both encodings get cheaper.
Source and scoped tasks use exact reconstruction. This general criterion is
not a completed numerical learner or an approximate search implementation.

The scoped control replaces eight of nine occurrences and preserves a ninth
whose repeated parameter disagrees across rule components. Complete bytes fall
from 80,680 to 26,890. This is a synthetic scoped representation control, not a
held-out library result, a runtime speedup or a general compression-quality claim.

  make test-binary-value
  make test-ic-scoped-archive

Corpus-guided scoped discovery
------------------------------
Import lib/petta/lib_scoped_grammar.metta to generate templates automatically
inside a declared finite scoped family:

  (scoped-grammar:enumerate family ordinary-context root-sorts sources depth)
  (ic:learn-scoped original-bytes
    (IC:Grammar family name ordinary-context root-sorts depth) quantum)

The first operation yields Scoped:Template forests for one guide occurrence.
The second returns the same IC:PreparedSearch used by supplied candidates.
The family's base signature must agree with the archive. Parameter declarations
and the ordinary context specify the finite leaf choices; this entry point does
not synthesize new higher-order parameter declarations or perform general
higher-order anti-unification.

Depth bounds retained rigid constructors. At each source position the generator
may retain the actual constructor, preserve the actual bound variable, introduce
an ordinary closed-image variable, or apply a declared contextual parameter to
distinct correctly sorted bound variables. Subsets and permutations are covered.
The matcher is run as choices are made, threading one capture environment through
all siblings and rule components. A captured subtree need not fit within the
rigid-constructor depth bound. An exhausted empty region is not a budget stop.

Every compatible corpus occurrence can guide refinement. Identical guide
forests are generated once; their source occurrences still count separately
when factoring and computing support. Different guides can generate the same
template. No unproved cost bound or match-based dominance heuristic suppresses
those proposals. Final source reconstruction and complete-byte acceptance are
unchanged. The generator does not execute operator names or install helpers
into an application.

An independent implementation enumerates the full syntactic products first and
matches complete forests afterward. The focused gate compares its finite regions
with early capture pruning, then independently computes every complete candidate
cost. In the small binding corpus, eleven proposals find the 8,350-byte minimum
from a 15,073-byte original. This is bounded search coverage and representation
savings, not a held-out real-library execution claim.

ScopedGuidance.lean proves that interleaved matching gives exactly the ordered
late-filtered candidate account, including duplicates, and independently expands
each successful template. ScopedChoices.lean constructs finite sorted variable
and contextual-spine choices and connects that equality to checked refinement
under a complete cost. Concrete controls cover a generated binding template,
the depth boundary, repeated-spine refusal and unused uninhabited parameters.
Finite runtime conformance is separate from these algorithm laws.

Owned fair search now reuses the existing generated structural-operation
contracts for expression construction, deconstruction and concatenation. Binding
patterns, like case patterns, are not executed by the relation-safety scan; their
source values and bodies are still checked. Only the imported unary exact-integer
observer receives native purity permission; physical value-kind classification
does not. Other codec calls,
wrong arities, effects and unavailable providers stay conservatively refused.
The safety cache records native observer availability as well as the program
token, including loaded-module availability without a source edit. This does not
grant type-level evaluation permission or blanket purity to native libraries.

  make test-native-observer-safety
  make test-scoped-grammar

Complete first-order archives
----------------------------
lib/petta/lib_binary_tree.metta carries nested records without unpacking numeric
payloads into atoms. A leaf is the framed pair (empty-marker, payload). A node is
the framed triple (one-marker, tag, framed-vector-of-child-records). The marker
for one is the byte 0x01; zero has an empty payload. Both payloads and tags are
rank-one U8 tensors. Decoding derives its budget from the actual encoded bit
length. Extra fields, invalid markers and malformed nested frames are refused.

lib/petta/lib_binary_schema.metta maps registered constructors to these trees.
The schema declares each positive numeric tag, constructor and field kinds:
Bytes, Text, Symbol, Natural, Record, Either and Vector. Vector records use tag
zero. Duplicate tags/names, unknown field kinds and dangling constructor names
are rejected on registration. One table governs reading and writing.

lib/petta/lib_ic_archive.metta declares IC1 and supplies its observation checker:

  (IC:Archive "IC1" observation signature heads literals definitions residuals)

The signature and slots use the template representation above. Each head is
(IC:Name text) or (IC:LiteralRef index). The literal dictionary stores
(IC:Literal kind bytes), with U8, I64, F64, String and Symbol kinds. Integers and
binary64 literals use eight big-endian bytes. Symbol and String literals use
UTF-8; String permits embedded NUL. Literal heads must have arity zero.

A definition is (IC:Definition name root-slots patterns). A residual packet is
(IC:Raw root-slots sources) or (IC:Call definition-index environment). Calls carry
one explicit (IC:Binding role index source) per required hole. Missing, duplicate,
unknown and wrongly sorted bindings are rejected. All definitions currently use
base operators; recursive/inter-definition references and binder adapters remain
outside this first-order profile. Packet order and duplicate occurrences survive
restoration. Head/literal tables are fixed for an admitted task.

  (ic-archive:pack archive)
  (ic-archive:unpack bytes)
  (ic-archive:check original current candidate)
  (ic-archive:factor current name root-slots patterns)
  (ic-archive:install original current name root-slots patterns)
  (ic-archive:learn-pair original current name left-index right-index)

pack returns Binary:TreeBytes or Binary:TreeFault. unpack validates both syntax
and semantics before returning IC:Some archive. check accepts only a candidate
that reconstructs the original task, retains its catalogue/observation and has
strictly fewer complete serialized bytes than the current artifact. It returns
IC:ArchiveAccepted with the candidate, bytes and before/after sizes, or a reason
for rejection. Definitions, their names, all substitutions and framing are paid.
An unused or excessively large definition can therefore lose despite reducing
the count of source nodes.

factor builds a proposal at disjoint packet roots. install checks that proposal;
learn-pair derives its seed from two selected packets and tries it on every
compatible packet. These operations produce inspectable data and never edit
application sources. They are components of the learner: the fair scheduler,
top-down candidate grammar, source adapters and library exporter remain open.

The current profile is (IC:Observation ExactSyntax empty-bytes). Numerical
approximation requires a separate declared observation against the original
task. Transported definitions never acquire execution or certificate authority.

Resumable search
----------------
lib/petta/lib_ic_search.metta supplies one cooperative controller for candidate
streams. The current model is IC:ProgramArchive. A producer returns
(IC:Candidate archive) or (IC:ProducerFault reason); every candidate is checked
against the original task. Rejection never discards the producer's later answers.

The ordinary work library exposes the existing retained-computation engine on
plain PeTTa:

  !(import! &self (library work))

work-new holds its source unevaluated. work-budget bounds a take in machine
transitions, work-take retains the remaining alternatives, and work-cancel
releases the resource. work:epoch is an opaque token that changes on a mutating
work operation. ID arithmetic or print/reparse cannot supply an owning reference.
The ordinary heap library exposes the persistent pairing-heap implementation
without a Prolog import: heap:empty, heap:insert, heap:take, heap:size and
heap:valid?. Operations preserve valid heaps; validate untrusted data once at
the boundary. Equal keys retain the established meld tie order; composite
(priority serial) keys give deterministic age ties.

Search entry points are:

  (ic:prepare model original sources quantum branches)
  (ic:resume state slices)
  (ic:cancel state)
  (ic:release state)

branches contains (IC:Branch priority work-handle) values. Each producer must be
fresh, owned, distinct and qualified for the common FIFO continuation route.
Preparation returns IC:PreparedSearch state or IC:SearchRefused reason. The
named ic-search:from-list relation supplies a finite stream without dropping
duplicates. sources lists every mutable source space declared by the operator
adapter; preparation captures their actual revisions. Dependency inference for
arbitrary user code is not supplied by this API.

The work library also exposes work:source-epoch and work:source-status. A source
epoch retains the lifetime-qualified instance identity, own revision and live
base/module dependency epoch as complete decimal uint64 fields. Capture and
validation resolve the source and inspect it inside one protected physical read.
Validation returns Work:Current or Work:Changed; invalid or closed sources return
Work:Fault. This is a currency observation, not execution or borrowing authority.
IC guards now use these complete views, including nested overlay dependencies;
a base-prefix rewrite can invalidate a task without moving the overlay's own
revision. A masked append outside a frozen prefix need not invalidate that view.

Seven services choose the least priority, keeping age order on ties. The eighth
chooses the oldest pending ticket. A paused producer rejoins with a fresh ticket.
The first queue implementation is the ordinary list reference from FairQueue.lean;
indexed persistent frontiers remain a separate runtime facility. Both the outer
queue and the producer's admitted FIFO route preserve later alternatives.

resume returns (IC:SearchResult best statistics reason first-fault state).
Statistics count services, candidates, accepted improvements and faults. Only
the first fault detail is retained, with all faults counted. Reasons distinguish
RegionExhausted, FaultedRegion, BudgetExhausted, Cancelled and Capacity. Exhaustion
refers to the supplied producer region; it does not assert incompressibility.
Every supported resume checks the task observation, complete source views and cursor
epochs. A consumed earlier snapshot returns CursorChanged rather than replaying
an advanced cursor. Handles remain in-process resources and cannot be recovered
from serialized identifiers.

Search cancellation is a cooperative pause at a slice boundary, retaining the
latest state for resume. release is the explicit destructive resource operation.
Terminal producers are released by the controller. Hard process termination is
not a durable search checkpoint. Quantum bounds cooperative machine work; the
fairness bound counts slices, not elapsed seconds.

The controller checks source dependencies at slice boundaries. Operator adapters
must declare all mutable sources they read. The current archive model preserves
exact syntax; numerical approximation needs its declared observation model.
The supplied-stream controller is not the full template-grammar or numerical
proposal learner: those families and their completeness controls remain open.

In syntax factoring, extraction replaces exact matching subtrees by a fresh
reference. It refuses an ID already present in the current source. Reconstruction
expands features in reverse extraction order and restores the exact ordered tree.
Original rule multiplicity, names and binding syntax are therefore retained when
included in the input tree. The compact representation is not itself authorized
as a new rewrite system. Direct compact execution needs a separate correspondence.

Reachable search and residual-bounded information
------------------------------------------------
Mettapedia's Compression.FairSearch proves that the actual cost/age queue
services each live occurrence within its ticket deadline and eventually services
every node on every finite successor path. Successors may include a continuing
cheap branch. Empty residual work certifies coverage of the rooted region.
A finite instruction or scheduler budget does not certify that coverage.
The complete-byte checker consequently eventually matches or improves any
reachable valid candidate, and a completed region supplies the corresponding
minimum-cost bound. These are algorithm laws over cooperative slices; native
work-handle conformance is checked independently.

FeatureGlobalSearch connects this queue to the shared effective conditional
interpreter. Each source and checked residual keeps an enumerator of all
descriptive/feature program pairs. Extraction trials and reconstruction trials
retain their own bounded evaluator stages; nonreturning trials coexist with
later pairs and deeper residual searches. One interpreter code is fixed before
all sources and finite valid chains. Every such nonempty chain is eventually
published by the actual scheduler, and every finite-prefix publication
reconstructs the source through the complete mathematical scheme codec.

The greedy variant keeps its local queue until the first checked publication,
then commits and starts a local search on that residual. Its finite prefixes
reconstruct, sliced execution composes exactly, and an available valid step
eventually causes an actual commitment despite competing divergent trials.
It need not choose a given chain or an ideal shortest feature. Unbounded pair
enumeration never certifies exhaustion from a finite budget, even on an empty
source that cannot have a strict feature.

These are the project's eight-turn cost/age algorithms, not an identification
with the IC paper's dyadic allocation. Mathlib Code.evaln bounds evaluator
stages and intermediate naturals; it is not a Turing-machine instruction
counter. The following separate dyadic construction uses machine transitions.

Machine-backed dyadic one-step search
------------------------------------
Machines.PrefixPortfolio reuses the existing finite bitstring enumeration,
Kraft inequality and Levin portfolio. Prefix-free code admission derives the
phase budget rather than assuming it. Each admitted word keeps its own worker
configuration. Resuming from a later phase retains those configurations and
the phase clock; it does not restart their computations.

The main convention admits code lengths at most the phase and allocates
2^(phase - code_length) slots. The IC pseudocode's strict length comparison
and its proof's inclusive comparison are kept explicit: strict eligibility
at phase i+1 matches inclusive eligibility at phase i, with twice the budget.
This relation concerns allocated slots, including reservations after a halt.

Machines.PrefixMachine connects those workers to Mathlib's actual compiled
four-stack TM2 transitions, with a finite control-support witness. Its output
reader requires termination, a single encoded output and canonical encoding.
A number that decodes to a value is not automatically that value's canonical
code. The kernel controls distinguish the eighth and ninth transitions of a
compiled successor, and refuse noncanonical or extra outputs.

FeatureDyadicSearch compiles one checked autoencoder before all sources and
program pairs. It performs extraction, reconstruction and strict shortening.
A completed but rejected pair returns no candidate; it cannot hide a later
worker answer. Every publication reconstructs the source, and every real
two-way compression step is eventually published with the allocation bound

  allocated_slots <= 4 * 2^L * max(tau, 1),

where tau is its compiled TM2 transition count and L is the complete existing
canonical record length for [descriptive_program, feature_program]. Exactly,

  L = 7 + length(e2(descriptive_program)) + length(e2(feature_program)).

All framing headers are charged. A proved counterexample shows that arbitrary
plain programs cannot be framed with one uniform additive overhead. The bound
does not replace L by raw component lengths plus an assumed constant.

This component is a checked one-step dyadic search. Allocated transition slots
exclude output decoding, portfolio administration, Lean execution time and native
learner wall time. No change to the native learner's eight-turn policy is implied.

Retained hierarchical dyadic search
----------------------------------
Machines.ResumablePrefixClock turns the inclusive-phase portfolio into a
single-turn machine. A turn loads a phase or services one worker slot. Its
complete-phase execution agrees with the existing batched portfolio. Both the
phase cursor and the unfinished worker states survive a sliced run.

Machines.HierarchicalPrefixSearch gives every codeword its own running,
rejected or child-search state. A successful local worker opens a child search;
that branch's later allocations service the child, not a restarted local trial.
Other workers and child searches remain live, including divergent competitors.
The construction uses the shared inclusive phase profile. It is not an equality
with the printed strict-phase pseudocode or the native eight-turn scheduler.

HierarchicalPrefixLaws proves a simultaneous invariant over all branches:
running configurations are finite prefixes of their actual workers, and every
child has a real worker readout and a sound retained child search. The Boolean
path observer agrees with the independently stated retained-path relation.
Resumption preserves the whole tree, not merely the selected successful path.

FeatureHierarchicalSearch instantiates this machinery with the compiled checked
four-stack autoencoder. One compiled checker is fixed before all sources and
finite strict compression chains. Depth equal to the original source length
loses no such chain, since each successful step strictly shortens the residual.
Every observed path reconstructs the original through the shared scheme codec.
For codeword a_i, let L_i be its complete canonical pair-record length and tau_i
its actual checked-worker TM2 transition count. The live hierarchy reaches the
chain within B turns, where

  B([]) = 0
  B((a_i, tau_i) :: rest) = 8 * 2^L_i * (tau_i + 1 + B(rest)).

This equals the fully charged cumulative-weight sum

  sum_i 2^(L_1 + ... + L_i + 3*i) * (tau_i + 1),

with one-based i. Prefix freeness derives the allocation bound; no assumption
that competing workers terminate is needed. HierarchicalPrefixCost independently
counts successful local transitions and administrative selectors on the branch
actually serviced by each root turn. At most one worker transition and at most
source_length selectors occur per root turn. Debit totals compose across resume.

The focused controls run a two-level search with a shorter endless competitor
and two successful siblings at both levels. They distinguish insufficient fuel,
wrong answers, depth limits and unadmitted words; they also execute a real
compiled four-stack worker and a two-step compression chain.

The audit checks the safe logical declarations and their theorem dependencies.
Lean-generated recursive compiler implementations are recorded separately,
matched to safe definitions with the same types, universe parameters and module
owners, and never used as kernel proof evidence. Direct references to nonlogical
helpers in the checked types or bodies are refused.
The control proofs are kernel checked without native decision procedures.

This is a recursive allocation result, not the full interpreter-time theorem.
Phase-list construction, worker initialization, output decoding and description
materialization have variable costs outside the selector count. A linear join
from the compiled checked-worker count to the underlying interpreter's separate
extraction/reconstruction costs, strict-profile realization and quantitative
greedy commitments remain qualification obligations. No native speedup follows.

Original machine-time components
-------------------------------
Computability.StackMachinePortTime derives fixed push/pop constants from the
actual finite command table. A macrostep can contain several primitive stack
operations. For a completed clean run with distinct input/output ports,

  input_cells <= machine_pop_bound * original_transitions
  output_cells <= machine_push_bound * original_transitions.

The port condition is necessary: the actual in-place identity returns an
arbitrarily long input word in one transition. It therefore refutes every
uniform output-length/time factor if that condition is omitted.

StackMachineOutputRelay executes the original machine, the existing two-pass
physical handoff and a symbol-by-symbol copy into a separate output arena.
An original run taking t transitions and returning n cells has a relay run
within t + 6*n + 4 transitions. If the source already has distinct ports, the
output term is paid by its computed push bound. Otherwise the general bound
retains an explicit 6*input_cells term; in-place output does not become free
physical copying.

StackMachineCompositionReflection extracts the first original halting prefix
from the actual completed composite trace. With a clean-halting source, relay
outputs reflect to original outputs, and the relay itself has clean halts.
Here clean means the canonical output configuration, with other stacks empty
and registers reset, not merely a halted label. A dirty-halt control shows why
this is a real semantic premise.

Machines.FiniteStackWorker connects counted finite-machine executions to the
retained searcher in the same transition budget. Readouts reflect to counted
executions for clean-halting machines. Input construction and interpretation
of a returned physical word remain separate operations.

HierarchicalSourceTime joins two original source runs through the actual
physical composition. With distinct first-program ports the local bound is

  (1 + 2*first_machine_push_bound)*first_time + second_time + 2.

Actual typed source-call paths are converted to retained-worker paths, then
reached by the existing live hierarchy with its cumulative codeword-weight
bound. This is not a fast-compiler assumption. The concrete controls execute
copying and bit-negation programs, preserve order and duplicate positions,
distinguish the last transition from insufficient fuel, and replay two-call
source witnesses with their computed timing constants.

StackMachineContextCall retains the original argument on physical stacks while
the source program runs with its original transition count. Two argument passes
prepare the call. Output collection, reversal, a disjoint delimiter and argument
restoration produce an ordered tagged argument/result packet. The actual bound is

  source_time + 3*input_cells + 2*output_cells + 5.

For separated source ports the computed pop/push constants absorb both lengths
into a uniform linear source-time bound. In-place sources retain an explicit
input-copy term. Completed caller traces contain an actual original halting
prefix: the caller cannot turn source divergence into completion. Clean source
halts give canonical caller outputs and same-budget original-run reflection.
Controls cover changed and empty results, empty arguments, duplicate positions,
insufficient budgets, divergence and unhidden source garbage. This tagged physical
interface is not a second binary archive format or an IC acceptance checker.

FiniteSupportMachine restricts a proved closed finite label support to its actual
members. Original registers and physical stacks are unchanged. Embedding and
erasure preserve counted executions in both directions, with the same budget.
An out-of-support total-selector fallback supplies no source-correspondence law;
the closure proof is required and an omitted-target control refutes its absence.

FiniteCompiledMachine instantiates this restriction with the existing compiler's
codeSupp theorem. Its finite table is fixed before all inputs, not reconstructed
for each source argument. The resulting four-stack program has the original
machine-transition count. Its context-preserving caller returns the original
encoded input and result with the explicit word-copy bound above. Canonical
halts are proved at admitted trList inputs. The context and retained-worker
interfaces support that per-input contract without postulating clean behavior
on arbitrary malformed stack words. Controls compare the original nine-step
successor, its nine-step finite package and its 21-step context call, and recover
an actual original run from the observed caller packet. Input encoding and
output interpretation remain separate operations, not hidden constant-time work.

ConditionalSourceMachine presents one fixed source code before all program and
condition strings. It uses two separate fields of the existing trList physical
representation, rather than an uncharged outer natural-pair operation. Every
effective conditional algorithm with an exact natural-word codec has such a
presentation, including the existing plain universal conditional interpreter.
Source soundness and eventual completion are proved from the actual compiler;
context packets reflect both the original query and a genuine conditional
output with a counted source run. No compiler-speed or outer-encoding bound is
inferred from effective representability. The query reader rejects missing,
extra, unterminated and noncanonical fields. Actual-machine controls distinguish
program/condition order and change the input data while keeping the code fixed.
This input framing does not make the conditional program domain prefix-free.

NaturalWordEncoding consolidates the exact dense word/natural codec used by the
independent theory. Both round trips and primitive recursiveness are proved on
the shared foundations. The original-interpreter client proves encoder and
decoder correspondence, and this fifth shared interface is compiled by both
toolchains. The independent source remains unchanged.

NaturalWordMachine performs the physical conversion. One finite borrow and one
optional bit suffice; no growing natural or whole word enters the registers.
A scan and restoration produce the canonical compiler natural field, including
its delimiter, within 2*word_bits+3 original transitions. The field has between
word_bits+1 and word_bits+2 cells; a two-field query has between total_bits+2
and total_bits+4 cells. An already present suffix is retained without traversal;
placing or copying that suffix is still a caller action. A query run prepends
the encoded program to an already encoded condition. Controls include leading
zeros, an empty word, insufficient fuel, a 64-bit carry/borrow case and an
uninterpreted contextual suffix. These are formal machine counts, not native
CeTTa timing or allocation measurements.

FramedHeadCall executes an unchanged source on the first delimited field and
replaces only that field. The rest of the frame is physically copied in order,
including empty fields, delimiters and duplicate occurrences. The bound is
t+2*head_cells+2*output_cells+2*tail_cells+6. Completed calls reflect to an actual
counted source execution at the admitted input. A divergent source cannot
produce a completed caller; a missing first delimiter does not become an empty
argument. FramedFieldAssembly uses fixed groups of field indices to concatenate,
reorder or duplicate fields through the existing indexed template machine.

ICSourceCalls composes those mechanisms into two dependent calls. Starting from
[descriptive,feature,original], it forms the first query, keeps the original
metadata, then constructs the second query from the first returned residual.
The result frame is [rebuilt,feature,residual,original]. Both calls use the same
unchanged source. Its bound is t1+t2+128*(input_frame_cells+residual_cells+
rebuilt_cells+1), charging assembly, call setup, copying and physical handoff.
ICConditionalCalls joins the pipeline to the fixed conditional-interpreter
presentation: source code is selected before all task words. For the exact
dense codec, the additional bound is 128*(the five word lengths+14). Input
encoding preparation remains outside this clock. Actual compiled controls
increment the second argument: the first call returns 4 from 3, then the second
returns 5 from that residual. Substituting the original 3 is rejected as a wrong
result. This is a call-dataflow control, not successful compression.

WordDropLastMachine uses one pending symbol and a physical reversal to remove
a final symbol. NaturalWordDecodingMachine composes the existing digit reader
and binary incrementer with that buffer. On a canonical dense natural field,
the increment exposes the original word followed by its high sentinel; removing
it recovers every original bit. The bound is 24*(word_bits+1), including both
handoffs. Mapping a complete ordered frame costs at most 32*input_frame_cells+2.
Stored natural-field length is not original word length: the equally sized
fields for natural 2 and natural 3 decode to one and two original bits.
Arbitrary malformed natural-field admission is outside this image-domain law.

FramedCompressionCheck reads four original-word fields. It compares rebuilt
and original bits in order, while one marker for each feature or residual bit
is debited by original bits. Extra original bits are required for strict
shortening; leftover credit or unequal reconstruction refuses. Its output is
some(verdict) followed by the complete residual/feature frame. It counts all
reads, reversals, cleanup and publication within 4*(input_frame_cells+1).
Empty candidate fields, equal cost, wrong reconstruction, missing delimiters
and extra fields have distinct positive or refusal controls.

ICPhysicalCheck joins the dependent calls, dense decoding and this check.
For already encoded tasks its bound is t1+t2+256*(the five word lengths+9).
One fixed plain universal source precedes all task words. Terminal traces
reflect to both genuine source computations without assuming termination.
Every completed worker readout decodes to the mathematical executePair outcome,
including a completed refusal; either divergent source invocation prevents
publication. A compiled local source fixture supplies an accepted step and
a wrong reconstruction, both through the complete physical body. These are
mathematical IC word-cost controls, not complete native library-archive savings.

ICPreparedCheck starts with the original descriptive, feature and source words.
The existing framed mapper physically encodes every occurrence within
11*input_frame_cells+2 transitions. Its handoff and the checked body give the
joined bound t1+t2+288*(the five word lengths+9), with sound readout and clean
halts at the admitted original-word task. Serialized candidate-pair parsing
is a preceding stage, not an operation hidden in this preparation clock.

ICSourceClock declares the underlying source clock explicitly. A real
output-separated relay runs the original source, then transfers and copies
its result; original time t yields the bound t+6*output_cells+4. Completed
relay runs reflect original source runs at admitted queries without totality
assumptions. Its distinct physical ports supply actual input/output bounds.
One factor kappa, derived from that fixed relay's finite push/pop table before
all task words, bounds prepared checking by kappa*(normalized_Tg+normalized_Tf+1).
This does not identify normalized time with the old in-place interpreter clock.

PreparedICSearch retains that admitted prepared-worker interface. Its entryWorker
instead receives the actual raw candidate/source job and physically parses the
candidate before preparing and checking it. Every finite emitted candidate
reconstructs and strictly compresses, without assuming prior candidate admission.
Each valid step is published within
4*2^L*kappa_entry*(normalized_Tg+normalized_Tf+1) allocated worker slots, where L
is the complete existing pair-code length and kappa_entry=4*kappa. A single
normalized universal source precedes every task. Eligibility enumeration, initial
materialization, observer decoding and variable-cost scheduler administration
remain outside this slot clock. This is not the full hierarchical ALICE or
quantitative Greedy theorem.

BinaryCountdownMachine supplies the in-place counter needed by a physical E2
reader. It retains the counter width, reports success or zero explicitly, and
charges borrow scanning and restoration. A zero-bit potential proves amortized
debit-plus-one-payload-step costs; additional caller flag/dispatch operations
remain separate. Every reachable counter configuration uses at most input
width+1 physical stack cells, including publication. A 65-bit fixture crosses
64 zero bits and stays within 66 cells at every budget. E2 binaryBits headers
are big-endian; pushing them reverses them into the little-endian counter.
An unreversed-header control catches the wrong numerical count.

E2PairMachine physically reads the unchanged seven-bit count header followed by
the two E2 fields in pairCode(g,f). Its two-field input frame [pairCode(g,f),x]
becomes the three-field output frame [g,f,x], preserving empty fields, bit order
and duplicate occurrences. It validates the leading bit of nonempty binary
length headers and uses the countdown in the same arena. Status-prefix removal
and payload transfer share one fixed machine statement. The full valid-job bound
is 8*(input_job_cells+1), including cleanup, reversal and publication. Conversely,
every terminal execution implies an exact canonical job and the same output.
Malformed, truncated, noncanonical and extended jobs enter a nonpublishing
rejection loop; this is partial admission, not finite search exhaustion.

ICEntryCheck composes that parser with ICPreparedCheck. The complete worker bound
is t1+t2+320*(L+source_bits+residual_bits+rebuilt_bits+9). Its completed readout
agrees with the mathematical autoencoder, including completed refusals, and
invalid candidate codewords cannot complete at any budget. ICSourceClock derives
the fixed kappa_entry factor from actual normalized-source I/O bounds.

An independently spelled valid fixture publishes at transition 42, not 41;
another preserves three empty fields. Missing boundaries, extra fields and a
redundant zero-length header do not publish. A malformed 65-bit length announcing
2^64 payload bits reaches rejection with its counter still 65 bits wide. This
snapshot is not an all-reachable-state parser-space theorem or native-heap result.

The native artifact checker and the generic compiled autoencoder already exist.

the separately checked encoded-input body, ICPreparedCheck adds original-word
encoding, and ICEntryCheck adds physical candidate admission. Scheduler
eligibility/enumeration, initial materialization, observer decoding and variable
hierarchy administration still need a complete end-to-end cost join.
Effectiveness does not give the old general-purpose compiler a linear-time law.
Strict-profile realization and quantitative greedy timing
also remain open. Source-time component qualification is not native speedup,
WILLIAM-family discovery or held-out library evidence.

followed by the actual whole-pattern matcher. It proves equality of the complete
ordered candidate lists, including repeated candidates and shared captures.
Parameter roles, typed contexts and the finite leaf supply remain explicit.
This permits early capture pruning without changing the declared region's cost
optimum or tie order. Matched templates independently reconstruct their guides.

for the plain shortest-feature lower bound. General prefix and information

Uniform shortest-feature information
------------------------------------
The shared residual-search development constructs a partial-recursive search
for a residual, proves its soundness and completeness when a reconstructing
residual exists, and bounds the selected descriptive map. FeatureJointInformation
and FeatureDecompositionInformation retain feature/residual independence and
the source-conditioned residual description. FeatureIncrementalInformation
uses these results for a uniform information bound along an actual ShortestChain.

ConditionalInformationTransport provides prefix-machine composition,
information symmetry and the data-processing inequality of IC Lemma 3.4.
Pair swapping, condition selection and output projection are actual effective
machine transformations with charged compiler prefixes. Directional information
is a signed integer, not a truncated natural subtraction.

FeatureOrthogonality proves IC Theorem 3.5 on the same shared machines. There
is one constant C, chosen before every source, chain and pair of distinct
positions, such that

  |I_V(feature_i : feature_j)|
    <= |i-j| * (20 * floor(log2(source_length + 1)) + C).

Every step assumes a shortest feature and shortest descriptive map. The
canonical-machine controls discharge the universal/reference machine and
compiler premises, rather than replacing the theorem by a finite toy instance.
Positive and negative controls also cover positional splitting, directional
information and the failure of pointwise logarithmic bounds to imply a uniform
bound. These are checked mathematical laws, not a proof that the practical
bounded learner finds ideal shortest features or that the C implementation
refines the formal interpreter.

FeatureShortMaps proves the short-map bound corresponding to IC Theorem 3.8
over the same effective universal plain interpreter. One fixed compiler
followed by the feature supplies an extractor
for every source admitting that feature. A minimum descriptive map therefore
has length at most the feature length plus the compiler's fixed overhead.
For each fixed feature-length budget this is a source-independent bound;
the actual extracted residual has that same minimum plain conditional
complexity. The prefix-reference bound charges its separate framing overhead.
A fixed feature on arbitrarily large sources supplies a nonvacuous control.

FeatureConstrainedSearch applies an effective guard to every finite candidate
before selecting a residual. It proves partial recursiveness, soundness and
termination when an admitted reconstruction exists. For a fixed rational
factor p/q with q > 0, the guard is the exact integer comparison

  p * residual_length <= q * source_length.

Minimum ratio-restricted maps inherit the linear-in-feature bound. Together
with IC Theorem 3.7 this yields constant feature and map bounds for sources
compressible by a fixed rational factor greater than one. The actual selected
residual retains the ratio. No computability of comparison with an arbitrary
real factor is assumed.

The negative controls distinguish unrestricted and ratio-restricted minima.
Another two-answer control proves that filtering an already selected result
loses a later admitted answer, while filtering candidates before selection
reaches it. An actual partial-recursive search also reaches a ratio-admitted
residual despite a diverging earlier computation. These are mathematical
search laws, not a new native implementation or an ideal-optimality claim for
the practical learner.

Complete ideal-chain descriptions
--------------------------------
FeatureSchemeCodec defines an actual plain description of a feature chain:
a count field, the length-delimited feature frames in execution order and
the raw terminal residual. Its decoder is primitive recursive and its
interpreter is partial recursive. The exact bit length is

  final_length + 2 * sum(feature_lengths) + 3 * step_count + 1.

The count, frame headers and duplicate feature occurrences are all retained.
A missing frame is refused; reversing two noncommuting features changes the
result. A feature computation that does not return cannot fabricate an answer.
This mathematical packet does not replace the learner's portable artifacts.

FeatureRationalScheme specifies ideal shortest ratio-restricted steps and the
actual output of each minimum map. A finite scheme exists for every source,
stopping below the fixed cutoff or at a source not compressible by its factor.
ConditionalPlainComposition supplies the actual fixed compiler for transporting
complexity through bounded maps; the producer program is not doubled.

For every fixed rational b > 1, the complete plain packet has lower complexity
bound K_U(source) <= packet_bits + C and upper bound

  packet_bits <= b * K_U(source) + A * log(source_length + 1) + B.

The constants precede all sources and schemes. Feature lengths are uniformly
bounded and the number of steps is logarithmic. These are the effective
rational-factor, plain-source-interpreter counterparts of IC Theorem 3.9.

FeatureSchemePrefix wraps that packet with the existing exact E2 codec.
Its prefix interpreter rejects every nonempty extension of a complete frame.
The charged wrapper adds at most 2 * floor(log2(source_length + 1)) + 7 bits
over the plain packet. Actual compilers transfer the same two-sided form to
any stated effective prefix reference machine V, using K_V(source) on both
sides. The constants still precede all source data.

This does not identify shortest features of U with those of V, assume a
computable test for arbitrary real ratios or claim that practical discovery
finds these ideal minima. Canonical-machine controls include nonempty schemes
on arbitrarily large sources. A cross-format control also shows why framing
cannot be inferred from bytes: a raw packet can be a valid E2 field whose
decoded payload is a different bit string.

Features and finite-string randomness tests
------------------------------------------
FeatureRandomness proves IC Theorem 5.1 over the shared effective partial
interpreter. A fixed feature program gives each source the greatest saving
source_length - residual_length - 1 among its genuinely reconstructing,
strictly compressing residuals, or zero when there is no such residual.
One interpreter code, chosen before all feature programs, supplies uniform
primitive-recursive bounded-stage approximations. They are monotone and
eventually attain the value at each source; this gives no computable stopping
test for the limiting value. The counting proof uses output determinism of
the partial interpreter, not an arbitrary many-answer relation. Native source
observations and branch alternatives retain their own declared contracts.

For every source length n and threshold m the exact density bound is

  2^m * card({x : length(x) = n and deficiency(x) >= m}) <= 2^n.

No subtraction is truncated in that formula. The equivalent natural-power
interface used in the independent development needs both its bound by
2^(n-m) and empty levels when n < m. The shared equivalence proves why that
empty-level condition is necessary. A concrete negative control shows that
the truncated natural-power inequality alone can accept an invalid level.

RandomnessLevelSearch constructs an effective, append-only enumeration of
each level. Approximation times, source indices and evaluator stages are
dovetailed. Each newly discovered string gets one persistent index; later
discoveries never move an old address. The decoder searches for a fixed-width
index word of length n-m without deciding that the level is exhausted.
The same stable address book supplies one partial-recursive encoder for the
whole level. Every emitted residual has the declared width and decodes back
to its source; qualifying sources eventually receive such a residual.

FeatureRandomnessConverse proves IC Theorem 5.2 for compiler-universal
effective prefix machines and instantiates it with the existing concrete
trimmed prefix host. One feature covers every source whose deficiency exceeds
the feature's length. Its normalized length is exactly m-1. A binary threshold
header and one complete self-delimiting padding word pay for that normalization;
arbitrary ignored trailing bits are not assumed legal prefix programs.
Unboundedness gives an explicit source above the threshold, so the common
feature's class is nonempty. One actual descriptive-map program on the same
prefix host extracts all qualifying residuals. Both programs are selected
before the source quantifier, not separately chosen literal encoders.

FiniteBitStrings owns the effective enumeration, cardinality and fixed-width
index laws shared with PrefixPortfolio. The scheduler's existing public law
names remain available. Controls cover delayed earlier discoveries, repeated
strings, required padding delimiters, all nonempty suffixes, a bounded zero
test and a genuinely unbounded test induced by a fixed duplication program.
The declaration audit checks every new logical declaration's axiom closure.

These are finite-string test theorems, not an infinite-sequence measure-space
formalization, a runtime speed claim or evidence that a learned predicate
generalizes on real programs. Practical encoded-cost decrease supplies no
ideal shortest-feature or randomness-test hypothesis.

Uniform information for shortest b-features
------------------------------------------
FeatureResidualCap, FeatureBInformation, FeatureBDecomposition and FeatureBChain
establish the b-restricted information results of IC Lemma 3.5 on the shared
source interpreter and prefix reference machines. A minimum b-feature is not
assumed to be a minimum unrestricted feature. The same bounded residual is
retained when constructing a competing reconstruction program.

For every real factor b >= 1, its condition on natural residual lengths is
exactly a natural cap floor(source_length / b). The cap is explicit search
data, not a computation comparing arbitrary real numbers. One actual split-
description compiler handles sources whose shortest description is longer
than their residual cap. This supplies a uniform source-conditioned feature
bound and a polynomial bound on the number of minimum b-features.

The map compiler reads an E1-framed binary cap followed by the feature's prefix
description. It filters individual residual candidates before selecting an
answer, retaining later answers even when earlier computations diverge. Its
length bound includes every cap/header bit. The minimum b-map has length at
most 8 * floor(log2(source_length + 1)) plus a fixed overhead. No noncomputable
real factor is stored as a callable or granted a comparison oracle.

The information development proves incompressibility, both conditional
independence directions, joint independence, and source/feature/residual
decomposition. Its chain representation retains actual minimum b-programs
and their selected outputs. Both the incremental information discrepancy and
pairwise absolute signed information have uniform logarithmic budgets, with
coefficient 22. All compiler constants precede every factor and source.

Existing RationalScheme values map into these chains. The existing geometric
iteration bound then gives the squared-logarithmic information overhead for
every fixed b > 1, including an empty final residual. This is an ideal
information bound, not a new near-optimal native archive-length claim.

Executable helper boundaries
----------------------------
A reconstructing source template is not automatically a semantics-preserving
function extraction. An unannotated PeTTa helper call can evaluate an argument
before entering its definition. Discarding that parameter in the body does not
undo its effects or failure. Evaluating a choice once and reusing its value also
differs from independently evaluating that choice at each source occurrence.

The source-archive gate includes negative controls for unused effects, shared
choices and failed arguments, plus a positive control where the surrounding
function has already established its argument values. These observations are
about executable call boundaries, not failures of exact archive reconstruction.
An executable exporter needs the corresponding scope and argument-demand
conditions. Archive preparation and learning do not install helpers into
application sources or claim general extraction permission.

Entered-value source-library export
----------------------------------
lib/petta/lib_ic_library.metta supplies the first executable export profile:

  (ic:prepare-library document)

Documents come from syntax:read. The qualified profile is the active default
PeTTa reader; reader/profile changes are refused rather than silently changing
the interpretation. The suffix is text, and the generated name begins with
ic-learned:. It must round-trip as one symbol and be absent throughout the
original source, including quoted symbols.

The selected sites are whole right-hand sides of unannotated first-order
function equations. Each left side lists its distinct parameters directly.
Supported bodies use an explicit primitive grammar, quotation, choice
containers and the simple fresh-variable forms of let, sequential let*,
map-atom, filter-atom and foldl-atom. Each initializer is checked in its old
scope; the body sees exactly the declared new variables. Rebinding, compound
binding patterns, forward references and variable-headed calls remain outside
this profile. This is a learner admission rule, not a claim that those forms
are invalid PeTTa. Helper arguments are original entry variables or scalar
literals, never compound computations or local variables. Original function
entries, variable identities, equation order, duplicate clauses and unsupported
source forms remain intact.
The helper body may itself have effects, choice or failure; those behaviours
are not relocated into newly eager arguments.

exclude nonordinary entry forms. It is conservative and grants no purity or
value evidence. Declared Atom, String or Grounded types are not value evidence.

into arbitrary ambient spaces with extra declarations or reflective observers.
Installing a new definition is itself visible to a space observer. The exporter
returns source for review and does not perform that installation.

Source bodies project into the existing typed byte-tree learner. Per-occurrence
variable identities prevent unrelated equations from becoming one rigid local
variable. Repeated template holes share one argument, and the expansion checker
restores the original variable relationships. Search currently considers all
pairs of admitted bodies as template seeds; this is a finite seed region, not
the complete template grammar used by the separate scoped search.

lib/petta/lib_source_scope.metta owns the simple source-binding admission rule;

callers retain only their entry-name inventory. Expansion rebases the locals
after each caller's entries and restores the original inventory. All names
remain charged in the helper source. Generated port names avoid collisions
with those locals. The existing list library supplies inventory slicing.

This first local-frame profile shares only matching local-name inventories;
it does not silently erase binder names or claim general contextual-hole
export. General scoped matching remains owned by the separate Binding.Term

also cannot simply become a callable parameter: a new ordinary call would
evaluate its arguments first. The gate retains that negative control.

Typed numerical programs and bounded forward discovery
-----------------------------------------------------

Operator labels never become evaluator calls. Recipes select fixed authored

In particular, a free captured frame is not licensed merely because its eventual

The existing compact-DAG owner supplies chronological records, collision-checked

transport remains an explicit refusal; sparse external inputs retain their
actual support. TP1 packs the family, names, recipes, parameters, references,
constants and root vector through the existing BV1 codec. Decoding constructs
fresh owned DAG handles, validates the whole typed program and grants no
certificate authority.

Backward proposals and dynamically retained continuations
--------------------------------------------------------
lib/petta/lib_tensor_inverse.metta searches declared paths with one unknown
constant. Known siblings refer to the typed records of an ordinary tensor
program prefix. The family remains the same TF1 data, whether registered
directly or projected from a module; no decoded name becomes a callback.

  (tensor-program:prepare-inverse family input-sorts constants paths)
  (ic:prepare-fit Numeric:InversePrograms original-NC2-bytes region sources)
  (ic:fit Numeric:InversePrograms original-NC2-bytes region sources budget)
  (ic:predict Numeric:InversePrograms model-bytes new-inputs)

A path row is (TP:InversePath priority steps), with outermost operation first.
Steps are (TP:InverseBinary operator-index parameters missing-slot known-index)
or (TP:InverseUnary operator-index parameters). Missing slot is zero or one.
The current backward rules cover Add, Subtract, Multiply, Divide, fixed-shape
Broadcast and BroadcastLike (unknown scalar in slot zero). Known values and
intermediate targets must have compatible shapes and actual finite F64 storage.
Each completed path reconstructs an ordinary forward TP1 program, encoded and
checked through the same NC2 original-task and complete-cost authority.

For example, a Multiply whose missing second argument is broadcast like input
zero can infer a scalar coefficient from the observed input/output ratios.
The caller need not supply a coefficient bank. Paths may compose several
inverse operations and retain multiple ordered input dependencies. The
initial implementation does not infer arbitrary multi-unknown graphs or all
matrix/sequence inverses; those remain learner work.

Broadcast inversion proposes distinct observed scalar encodings. Unobserved
coordinates impose no scalar suggestion. When no coordinate is observed, it
proposes zero, which is still checked by the original task. Exact CTN1 bytes
identify duplicate parameter proposals; approximate equality is never used
for keys. Original rows, order, masks and evidence multiplicity are untouched.
Duplicate/masked coordinates are scanned in bounded cooperative slices;
distinct answers are yielded separately, with later alternatives retained.

IC:Continue carries a priority and inert proposal data. The common IC controller
creates, owns, queues and releases its cursor. IC:Responses injects a finite
ordered event block; faults are recorded without swallowing later events.
Materialization and numerical work run outside retained generators. Dynamic
continuations use the existing seven cost turns followed by one oldest-entry
turn; cancellation, cursor epochs, dependency guards and original-winner
checking remain common machinery. These mechanisms are available to other
artifact proposal families, not special evaluator dispatch for IC examples.

Backward binary64 formulas are proposal heuristics, not exact preimage solvers.
Zero multiplication can relax a parameter constraint, but cannot certify a
nonzero target. Division/rounding, tolerance and all unobserved positions are
resolved by replaying the complete forward program against the original
observation. RegionExhausted covers the declared finite path/sample proposal
region, not all floating-point models or global incompressibility.

MaskedScalarInverse proves exact field fibers for masked addition, subtraction
and multiplication, the zero-product consistency distinction, and the precise
extra check required by a relaxed proposal constraint. These are not binary64
identities. EvidenceSampling proves that bounded scans preserve the remaining
ordered distinct-answer stream and that every sample reaches service under the
cost/age queue, even with arbitrary competing branches. Its logical suffix,
physical packed cursor, scalar codec and no-observation default are separate
interfaces. Neither development claims C-evaluator refinement.

Contextual source helpers
-------------------------
lib/petta/lib_source_context.metta inventories evaluation positions and available
source variables. lib/petta/lib_ic_context_library.metta learns ordinary source
helpers at those positions, including bodies nested in let, let*, case, map,

The public learner returns the common IC:PreparedSearch. Its declared region is
all ordered-by-position seed pairs, not a complete template grammar. Native
ranked-tree anti-unification proposes the shared skeleton; matching selects

Availability is not value readiness. Ordinary unannotated entry ports have
already entered their function. They and physically typed source scalar

that judgment. A declared String or Grounded label grants no such permission.

available. Other captured computations travel as zero-argument closures and
are forced at each original demand position. An unused branch therefore remains
unused, and repeated effects or nondeterministic requests are not cached away.

variables must already be available. General free-variable transport through
arbitrary opaque binders is not implemented.

The LC2 helper uses the existing Library:Archive schema and SIC1 envelope,
with the LC2 version in both places. The decoder performs syntactic expansion,
not evaluation. It rederives original evaluation sites and entry-port readiness,
checks every helper-call position and argument shape, and rejects quotation,
out-of-range ports, eager computations and source operator overrides. LC1
decoding and export remain available before and after importing LC2.

This is a standard, nonreflective PeTTa source profile. Definitions or annotations
overriding the listed demand constructors are refused. Changed ambient argument
strategies, context reflection and resource-sensitive observational equivalence
are outside the qualified profile. Exported helpers are reviewable source,
never automatically installed into an application or certified for native
execution. Ordinary preparation still makes its own admission judgment.

The source task is a raw NC2 F64 matrix with no external inputs, at least one
row, a same-shaped Bool mask and a nonnegative absolute tolerance. A region is
(TP:ClusterRegion prototype-counts starting-row-indices maximum-mean-updates).
Counts and starts are ordered finite lists; repeated entries remain repeated
trajectories. Counts are positive and at most the number of rows. Zero updates
still checks the initial seeded model. Empty regions are exhausted without
inventing a fit. Empty-coordinate rows remain legal; an empty source row axis
is refused by this fitting family.

The common IC scheduler retains and checks every candidate. Fitting slices row
scans and centroid updates into explicit validated continuations; budget
exhaustion and cancellation retain resumable state. Resumption rechecks source
dependencies and the original task. Arithmetic faults decline that proposal
branch without discarding an earlier checked winner. Stable centroid bytes end
only that deterministic trajectory, not the rest of the region.

The model is an ordinary TP1 GatherRows program stored inside NC2. Its complete
cost includes the family and operator names, centroid matrix, every ordered
row assignment, mask, tolerance and all framing. Nothing needed for prediction
is kept in an external cache. Approximate fit never becomes key equality.
Initial seeds and updated means must satisfy the original observations, not a
previous winner's approximate reconstruction. A proposal that does not reduce
the complete archive stays rejected.

The generic tensor:gather-rows operation selects the leading axis with an Index
vector, preserving request order, duplicates, explicit zeroes and missing
support. Bounds are checked even for zero-width rows. TP:GatherRows uses the
same operation after an exact I64-to-Index cast. Existing recipe ordinals are
unchanged. The Operators.module adapter produces the same declared family.

tensor-program:compact-constant optionally encodes I64 literals with an explicit
TP:PackedConstant "I64Tensor" "u8" record. Every integer must cast exactly; the
decoder requires actual U8 storage and widens exactly. The complete tagged
record must be smaller than the ordinary literal. Normal constant construction
and existing CTN1 bytes are unchanged. There is no untagged dtype reinterpretation.

For example, this complete fitting invocation requires no supplied centroids:

  !(import! &self "lib/petta/lib_ic_clustering.metta")
  !(let* (($pair (tensor:from-values f64 (2) (-3.0 3.0)))
          ($points (tensor:reshape (tensor:view $pair (128 2) (0 1) 0) (256 1)))
          ($mask (tensor:view (tensor:from-values bool () (True)) (256 1) (0 0) 0)))
     (case (ic-arrays:prepare () $points $mask (Numeric:Absolute 0.0))
       (((IC:NumericArtifact $original)
         (ic:fit Numeric:Clusters $original (TP:ClusterRegion (2) (0) 2) () 1000)))))

Prediction returns IC:ClusterPrediction with an I64 assignment vector and an
F64 prototype reconstruction. Squared distances observe only masked coordinates;
ties select the first prototype. All-masked rows therefore select index zero.
An empty cluster coordinate retains its previous value. Missing seed coordinates
use zero only as a parameter guess; they are not imputed observations. New
matrices may have different row counts, including zero, but must retain the
fitted coordinate width. Strided inputs are normalized to owned logical rows.

The focused gates compare independent complete NC2/TP1 bytes, data-derived
seeds and mean updates, masked/duplicate rows, empty clusters and dimensions,
overflow, repeated trajectories, cancellation, sliced resumption, dependency
invalidation, malformed cursors and prediction on new points. The row-gather
gate also injects allocation failure through all allocation points exercised by
dense, sparse and empty construction. These gates extend the explicit joined IC
command, not ordinary make test. Lean proves logical row selection, tie/minimum
selection, stable partial updates and exact compact-literal/full-cost laws;
native C refinement and global clustering optimality are not claimed.
