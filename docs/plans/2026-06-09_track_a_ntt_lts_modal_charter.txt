================================================================================================
Date: 2026-06-09
Scope owner: Codex (implementation).  Charter/spec: analyst.
Status: ready to hand off.

This charter scopes the next concrete step of the OSLF/NTT integration. It is
deliberately narrow. It adds a reflective modal surface to the existing lts
library and pins ONE conformance slice in the reduction-relation vocabulary that
NTT is defined over. It does NOT touch the C kernel, does NOT introduce trace
emission, and does NOT begin the proof-kernel / he-prime / DTT work.


0. WHY THIS, WHY NOW (the decided ordering)
-------------------------------------------
The program is a two-track split with a hard dependency order:

  Track A — semantic waist / NTT: pin CeTTa's ACTUAL behaviour to
    LanguageDef -> ReductionSpan -> OSLF(diamond/box) -> NTT, and reflect that
    structure into the runtime.
  Track B — proof kernel / covers: theory-parametric PureKernel, HOTG/Megalodon
    + DTT covers, MTT/MATT bridges.

Rule: A outranks B in dependency. B must not pick a proof-kernel story that
outruns A's object-language pinning. The failure mode this prevents is "two
beautiful proof worlds proving things about a drifting MeTTa semantics."

Witness-extraction toward Lean theorem anchors, he-prime kernel slices, NatRec
iota, Fin/Vec indexed families — all Track B. They are OUT OF SCOPE here and
require explicit go-ahead before any work begins.

2. WHAT box IS, AND HOW IT IS COMPUTED
--------------------------------------
Over the one-step reduction relation, where (lts:transitions $step $state)
enumerates the successor frontier { q : state --> q }:

  diamond phi at p  ==  EXISTS q. p --> q  AND  phi(q)     ("some successor")
  box     phi at p  ==  FORALL q. p --> q THEN phi(q)      ("every successor";
                                                            vacuously True at a
                                                            normal form)

Grounding fact that makes box non-foreign: lts:is-normal-form IS box(FALSE-pred)
— "every successor satisfies FALSE" is exactly "there are no successors." And
lts:is-can-step IS diamond(TRUE-pred). The new operators GENERALIZE the two
quiescence checks the library already ships. These two equalities are the first
regression anchors (Section 6).

Computation is purely a .metta library surface over the existing frontier — NO C,
NO new primitive. Collapse the frontier, apply phi to each successor, and fold:

  Reference sketch (lib/lts.metta), matching the Error/quiescence contract that
  lts:is-normal-form already uses:

    (: lts:box     (-> Atom Atom Atom Bool))   ; step, phi, state
    (: lts:diamond (-> Atom Atom Atom Bool))   ; step, phi, state

    (= (lts:box $step $phi $state)
       (case (collapse ($step $state))
         ((((Error $ctx $msg)) (Error $ctx $msg))     ; pure single Error -> propagate
          (() True)                                    ; empty frontier -> box vacuously True
          ($frontier
             (foldl-atom $frontier True $acc $q
               (if $acc ($phi $q) False))))))          ; AND-fold; phi(q) must be Bool

    (= (lts:diamond $step $phi $state)
       (case (collapse ($step $state))
         ((((Error $ctx $msg)) (Error $ctx $msg))
          (() False)                                   ; empty frontier -> diamond False
          ($frontier
             (foldl-atom $frontier False $acc $q
               (if $acc True ($phi $q)))))))           ; OR-fold

  HE specialization (lib/lts/he.metta), exactly mirroring how the existing HE
  surface binds to lts:he:step-state + quote:

    (: lts:he:box     (-> Atom Atom Bool))   ; phi, state
    (: lts:he:diamond (-> Atom Atom Bool))
    (= (lts:he:box $phi $state)     (lts:box     lts:he:step-state $phi (quote $state)))
    (= (lts:he:diamond $phi $state) (lts:diamond lts:he:step-state $phi (quote $state)))

  phi is passed as a unary predicate symbol returning Bool, the same way $step is
  passed as a relation symbol today (e.g. (= (lts:const-true $q) True),
  (= (lts:const-false $q) False)).

  EDGE CASE for Codex to decide explicitly and TEST: a mixed frontier that
  contains an Error among non-Error successors (e.g. (q1 (Error ..) q2)).
  lts:is-normal-form only special-cases the PURE single Error ((Error ..)); a
  mixed frontier falls through to the catch-all. box/diamond must make the same
  choice consistently (either propagate Error from a mixed frontier, or fold phi
  over it) and a test must pin whichever is chosen. Match is-normal-form's
  existing behaviour unless there is a clear reason not to; document the choice
  in the @doc.


3. OPTIONAL SECOND DELIVERABLE — bounded diamond* / box*
--------------------------------------------------------
Multi-step reachability (diamond*) and invariance (box*) generalize trace-2.
HONESTY CONSTRAINT: unbounded diamond*/box* over a Turing-complete reduction
relation are undecidable. Only FUEL-BOUNDED versions are total and may be added:

    (lts:reachable-within $step $phi $state $fuel)   ; diamond^{<=fuel} phi
    (lts:invariant-within $step $phi $state $fuel)    ; box^{<=fuel} phi

If added, they MUST carry the bound in the name and @doc, and the @doc MUST state
that they are bounded approximations, not the unbounded modality. If the
recursion is awkward, ship only one-step box/diamond this pass and defer the
bounded multi-step to a follow-up. Do NOT name anything "lts:reachable" or
"lts:diamond-star" without an explicit fuel parameter — that would over-claim
decidability.

  present a per-run check as a proof.


5. NON-GOALS / HARD FENCES
--------------------------
  - NO trace or certificate surface. The flag
      no_runtime_trace_or_certificate_surface: True
    in the generated catalog and the gate at
      scripts/check_he_compat_semantic_suite.py
    that raises "catalog must explicitly forbid runtime trace/certificate surface"
    STAY IN PLACE. box/diamond are reflection over the live reduction relation,
    which is categorically different from emit-trace-and-replay. Conformance is
    TESTING (bag-equal); the spec is what gets proven about. This is the ITP
    shape and it is deliberate.
  - NO C / kernel change. box/diamond are pure .metta library definitions over
    the existing __cetta_lib_lts_he_transitions primitive.
  - NO Rung 3. box/diamond here are REFLECTION ONLY (expressiveness), not a guard.
    Using box to prune a search is the optimization, and it is Rung 3 / he-prime,
    deferred and approval-gated. Reflection alone is NOT a speedup and must not be
    sold as one (computing box by materializing the frontier is the same work as
    exploring it).
  - NO Track B. No proof-kernel slice, no he-prime DTT, no NatRec iota, no Fin/Vec
    indexed families, no "promote witness to theorem anchor." A outranks B.
  - NO module/import "contract" redesign. The surface.* / profile.* rule-IDs are
    spatial/policy, not reduction edges; they stay in the policy lane. The spatial
    half of spatial-behavioral types has no referent in this term-rewrite fragment
    yet (it lands when the atomspace / MORK / PathMap layer is typed — a later
    horizon).
